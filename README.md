# 任务指南 TaskGuide

> 个人任务管理系统 —— 支持"任务追踪 + 步骤拆解"（原神任务模式），钉在手机桌面和电脑屏幕边，专治"事情多总忘 + 拖延症"。

## 功能速览

- 📱 **手机端**（vivo，主力）：安卓 App + 桌面小部件 + 通知栏提醒
- 🖥️ **电脑端**（Win11）：桌面悬浮挂件（置顶/普通/托盘三模式），低资源占用
- 🔄 **双端同步**：局域网直连（手机当服务器），实时同步，断连自动降级离线
- 🎯 **任务追踪模式**：任务可追踪 → 拆解步骤 → 逐步推进，挂件时刻显示追踪卡片
- ✅ **5 种任务**：一次性 / 重复 / 无时限速记 / 定时习惯 / 周期目标
- 📊 **统计总结**（第二版）：完成率 / 拖延分析 / 习惯坚持 / 时段分析

## 技术栈

| 端 | 技术 |
|---|---|
| 手机 | Android 原生 Kotlin：Jetpack Compose + Room + AppWidget + WorkManager + Ktor 服务器 |
| 电脑 | Tauri 2：Rust 后端 + HTML/CSS/JS 前端 |
| 数据库 | 双端 SQLite（共用 schema.sql） |
| 同步 | HTTP 增量同步 + WebSocket 实时推送（局域网） |

## 约束

- 不使用任何第三方付费服务
- 电脑挂件闲置 CPU 接近 0，内存目标 30-60MB
- UI：毛玻璃 + 淡金（原神任务追踪风格），非黑体、普通字重、紧凑间距
