## 零、头号原则：**一切从名字出发**（2026-09-17 boss 两次强调）

> boss 原话：「**要告诉他们要按照名字来画**」「纯线条跟名字不沾边」

**正确顺序（不可颠倒）**：

1. **拆名字** —— 把等级名拆成字/词（例：星辰霸主 → 「星辰」+「霸主」；群星行者 → 「群星」+「行者」）
2. **逐字找图形落点** —— 什么形状能代表"星辰"？什么能代表"霸主"？每个字都要有落点
3. **再组合** —— 把各字的落点组成一个整体，不是拼贴
4. **自检** —— 出稿时**必须能指着图说出「这一笔对应名字里的哪个字」**。说不出来 = 不合格

**禁止**：先想"画什么好看"，再往上套名字。
**若某个字找不到图形落点** → 明确回复「建议改名 XX」并给出替代名 + 对应图形，不要硬画。

这条优先级**高于**后面所有技法条款。

## 一、两条铁律（我之前全踩了）

### ⭐ 1. 「大面积渐变铺底」是廉价感重灾区

设计守则原话：

> **避雷：荧光色 / 渐变色 = 廉价感重灾区**

高档做法是 **「黑色底 + 金色线条」** —— 注意是**线条**，不是金色块面。
金属质感靠 **多节点渐变网格**（complex gradient mesh）做**局部点睛**，不是把整个图形铺成渐变块。
低质 vs 高质对照表（搜到的原表）：

| 特征 | 低质 | 高质 |
| --- | --- | --- |
| 渐变 | 平涂或缺失 | **复杂多节点渐变网格** |
| 格式 | 只有 JPG/PNG | 含 SVG/EPS/AI（矢量可缩放） |
| 图层 | 压平 | 命名分组 |

**→ 结论（⚠️ 2026-09-17 修正）：按「名字的性质」分两种语言 ——

| 名字的性质 | 该用的语言 | 本项目例子 |
| --- | --- | --- |
| **几何符印类**（抽象、中心对称、不是实物） | 金色**线条** | 7 三层漩涡、6 六芒结界、3 六边浪印 |
| **具象实物类**（能在手上拿起来的东西） | **实心 + 硬边分面** | 8 皇冠、5 长剑、7 锚、3 盾、9 天书 |

**判据一句话：名字能不能在手上拿起来。能 → 实心；不能 → 线条。**

（我此前把「用线条」当成了普遍原则 —— 那是过度推广，boss 指出「我不认同只用线条描绘」后修正。）
两种语言共同的红线只有一条：**都不许用大面积渐变**。**

### ⭐ 2. 「通用的剪贴画风格图形」和「装饰细节太多」是图形类标志的两大死因

> Common Mistakes to Avoid：**Using too many decorative details**、**Relying on generic clip-art style crowns**、**Ignoring small-size legibility**

**→ 结论：「画得不够多细节」是错的，「细节过多」才是病。要往减法走。**

## 二、可执行的十条

1. **线条粗细必须有对比** —— 「细线显精致，粗线显力量」。主结构 2.6–2.9，细节 1.4–1.8。
2. **大留白** —— 「像苹果 LOGO 那样呼吸感十足」。图形占盘面 55%–70%，不塞满。
3. **减法** —— 只留 1 个核心元素；每个点/曲线都要回答「它是否帮助辨认」，答不出就删。
4. **剪影检验**（最有用的一条）—— **把图形填成纯黑，还能一眼认出来，底子才算成立。**
   比任何精细度检查都有效，出案必做。
5. **24px 检验** —— 搜到的原话是「Scale down to 24×24 px to see if the gradients hold up as an icon」。
   小尺寸糊了就继续简化，不是加细节。
6. **形状语言要和气质一致** —— 尖角 = 有力/精英；圆角 = 亲和；棱角 = 现代/精确。
7. **比例用黄金分割 0.618**，不要随手填。
8. **微弧度** —— 「所有直角改成 2° 圆角，更柔和」。
9. **金高光往青色偏一点点** —— 能避免金属金在暗底上「发浑、变土黄」。
10. **不许出现「金色压金色」** —— 徽章本体若也是金，底盘必须压低饱和度（本项目 v3 已定的「低饱和深墨底 + 亮金本体」）。

## 三、等级递进（LoL 段位体系的做法）

- **每级一种材质隐喻**：铁粗粝 → 青铜 → 白银光滑 → 黄金闪耀 → 铂金 → 祖母绿 → 钻石水晶 → 紫 → 红 → 青
- **装饰是克制地递增**，不是最高级堆满元素
- **最顶级才有资格用皇冠**（LoL 里皇冠只给王者）
- 高级段位用**翼状/环形外框**，比堆内部细节更显贵

## 四、对本项目十枚徽章的直接约束

1. 语言统一：与 **6C 六芒结界 / 7A 三层漩涡** 同族 —— **纯线条、零大面积渐变、大留白**
2. 每枚必须有**实心或线条的明确剪影**，十枚剪影互斥
3. 出案时**必须附纯黑剪影检验**（我此前的案子从来没做过这道检验 —— 这次补上）
4. 底盘：低饱和深墨 + 一圈等级色细环（v3 已定）
5. 细节上限 5 件；小尺寸（38px）优先于大图好看

## 六、线条技法（第二批检索：line art / premium icon 技法文）

> 起因：boss 说线条版「还有提升的空间」。补课后发现我第一版线条**线宽只有应有的一半**。

### ⭐ 1. 线宽必须按「显示尺寸」换算，不能凭感觉

检索到的行业标准：

> For luxury branding, a common standard is the **2px stroke on a 24x24 pixel grid**.
> stroke weights between **1.5pt and 2.5pt** are perceived as more "elegant" compared to heavier, 4pt "chunky" styles.

本项目换算（盘面按 38px 显示、设计坐标盘径 124 单位）：
- 缩放因子 = 38 / 124 ≈ 0.306
- 要达到显示 2.2px → 线宽 = 2.2 / 0.306 ≈ **7.2 单位**
- 按图形自身宽度换算（皇冠宽 68 单位 ≈ 显示 20.8px）：**≈5.5 单位**

**→ 结论：主轮廓 5.5；v1 我用的 2.9，只有一半，所以"轻飘、立不住"。**

### ⭐ 2. 缝隙必须 ≥ 线宽

> Ensure the gaps between strokes are **at least equal to the stroke weight itself**.

否则会 **clogging**（堵塞）—— 密集的峰在小尺寸下糊成一团。
**→ 皇冠峰距必须大于线宽。** v1 五峰峰距只有 5 而线宽 2.9，v2 把峰距拉到 26。

### ⭐ 3. 重叠处要「擦掉被遮挡的线」

> Draw the closest object fully. Draw the object behind it **partially hidden. Erase the lines you shouldn't see.**

这是产生**前后深度**的关键手段。所有线条都"透明可见" = 平面、无层次。

### ⭐ 4. 断线（Implied Lines）

> Break lines where the form **curves away from the viewer**. Break lines near bright highlight areas.

在形体转离观者的位置留小口 → 透气、高级。**注意：只画一半比画全更高级。**

### 5. 三级线宽体系

**2 / 1 / 0.5**（轮廓 / 内部细节 / 纹理）。本项目对应 5.5 / 2.6 / 1.6。

### 6. 端帽必须统一

全套统一 `round` 或 `butt`，混用会破坏专业感。本项目统一 **round**。

### 7. 线宽的心理学

- **1–1.5pt → 精致、奢华、科技感**（高端钟表、时装屋）
- 2.5–3pt → 稳重、亲和、易用

### 8. 一致性铁律

线宽是整个 icon 集的**数学常量**：简单图标和复杂图标必须用同一条线宽。
复杂图标**靠删细节**避免视觉过重，**不是靠把线变细**。

### 9. 测试

100% / 200% / 500% 三档都要看。对角线的视觉会比水平线细，必要时给对角线 +0.05px 做**光学补偿**。

### 10. 还能继续提升的方向（boss 说"还有空间"时按此推进）

- [ ] 峰的不对称微调（打破机械感，但要保持整体均衡）
- [ ] 宝石从实心块改为**刻面线条**
- [ ] 加入**极少量点睛高光**（仅一颗宝石/一个球，不是整片铺）
- [ ] 用**黄金分割**校一遍比例（0.618）
- [ ] 全套十枚统一线宽常量

## 七、实心分面技法（boss：「我不认同只用线条描绘」后补）

### 「实心但不廉价」的四条

boss 说之前的实心版「廉价」——**问题不在「实心」，在于这四件事没做对**：

1. ⭐ **不用渐变，用硬边界色块分面**
   左受光面 / 主色 / 右背光面，**边界清晰**。渐变糊过去正是廉价感的来源。
2. ⭐ **色阶要少而清晰**（⚠️ 适用范围见第八节）
   扁平档：亮面 `#F6E5AE` / 主色 `#D2A93F` / 暗面 `#8A6414`（3 阶）
   **色阶越多越脏，少反而高级** —— 但**金属质感需要更多阶**（见第八节），
   两者的共同要求是：**每一阶的边界必须清晰锐利**。
3. ⭐ **描边要细而深棕**：`#2A1B05`，宽约 1.8
   不用纯黑、不用粗黑边 —— **粗黑描边 = 贴纸感 = 廉价**。
4. ⭐ **用结构线强化厚度**
   冠圈上下各压一条亮线 / 暗线，让「圈」看起来是个立体环，而不是一条扁带。

### 扁平插画的分面逻辑

- 分面边界要**沿结构走**（冠圈的上下沿、峰的左右侧），不要随便斜切
- 面积配比参考：亮面 ≈35% / 主色 ≈40% / 暗面 ≈25%
- 若要更强的贵气感，**只给唯一一个部件**加一处真高光（例如顶球的一小段弧形白线）——
  这叫**点睛**，不是铺渐变
- 盘底仍守 v3 定的「低饱和深墨 + 一圈等级色细环」，避免金压金

### 自查（实心类专用）

- [ ] 是不是只有 3 个色阶？
- [ ] 分面边界是不是清晰（不是渐变过渡）？
- [ ] 描边是不是细而深棕（不是粗黑）？
- [ ] 有没有给「圈/带」压亮暗线做出厚度？
- [ ] 高光是否只出现在一处？


### 点缀的秩序感（boss：「太简约了，高级的徽章应该更多点东西点缀」后补）

boss 认可了「实心三色阶分面」的底子，但要求**更多点缀**。
**⚠️ 这与第一节「装饰细节太多是死因」不矛盾 —— 区别在于「有秩序」还是「乱堆」。**

**三条秩序规则（点缀是否显贵就靠这个）**：

1. **等距** —— 同排装饰件的间距必须一致（冠带宝石等距排布）
2. **沿结构** —— 装饰要落在结构点上（峰顶珠落在峰顶，不是随便撒）
3. **对称 + 分级** —— 左右镜像；大小按中心对称递增（中央最大、向外递减）

**可用的装饰件清单（按 38px 下的性价比排序）**：

| 装饰件 | 说明 | 小尺寸存活 |
| --- | --- | --- |
| 冠带宝石排 | 5 颗菱形，中央大两侧小 | ✅ 最好 |
| 峰顶珠 | 每峰一颗圆球 | ✅ 好 |
| 顶部星芒 | 八芒星 + 放射线 | ✅ 好 |
| 冠圈上下压线 | 做厚度用 | ✅ 好 |
| 伴星 | 左右对称 2 枚 | ⚠️ 尚可 |
| 外圈放射纹 | 8 等分短线 | ⚠️ 尚可 |
| 底部飘带 | 从冠圈垂下 | ⚠️ 尚可 |
| 拱上珍珠串 | 仅拱冠类 | ⚠️ 尚可 |

**尺寸取舍原则**：装饰越多，38px 越糊。优先级 = **冠带宝石 > 峰顶珠 > 顶星 > 外圈纹 > 飘带**。
小尺寸糊掉时**按此顺序砍**，不要平均减弱（那样全都看不清）。

## 八、金属质感渲染（boss：「金属质感还是不够，加深一点」后补）

### 病灶诊断

之前的「三色阶」跨度太小 —— 暗部 `#8A6414` 仍是**脏黄**，所以看着像**塑料**。
金属与塑料的分界就在：**金属的明暗跨度极大**（反光率极高）。

### ⭐ 金属四要件

1. **明暗跨度拉大**
   亮部接近**纯白**、暗部接近**黑褐**。中间不要留太多"脏黄"。
2. **边缘光（Rim Light）**
   在**受光侧**的轮廓**内侧**压一条近白细线（宽 1.5–2.0）。
   这是金属"起范儿"最快的一招。
3. **反射光（Bounce Light）**
   在**暗部底缘**加一道微亮（主色半透明）。
   模拟"金属反射环境光" —— **这是金属与塑料最大的区别**。
4. **柱面反光带**
   形体有弧面时（冠圈、拱、圆柱件），用 **5–7 条明暗相间的带** 模拟金属圆柱的反光条纹。
   带子要**斜向**（顺光方向），不要竖直。

### 本项目金属金·色板

| 用途 | 色值 |
| --- | --- |
| 高光 / 边缘光 | `#FFFFFF` |
| 亮面 | `#F7E7B0` |
| 次亮 | `#D9AC44` |
| **主色** | `#C8962A` |
| 暗面 | `#6B4A0A` |
| 最暗 | `#382404` |
| 描边 | `#1E1503`（深棕近黑） |

### 与「色阶要少」的关系

- **扁平图标签**：3 阶（少而清晰）
- **金属质感件**：4–7 阶（少了"深"不下去）
- **共同红线**：每一阶**边界必须清晰锐利**，绝不用渐变过渡

## 九、指挥 AI 画实物的配方（2026-09-18 立，王座"像马桶"事件）

### 教训

只说「画一个王座」，AI 会画成马桶。因为它不知道**「王座之所以是王座」靠哪几个结构**。
上一版失败稿的数值：靠背 ±23 窄板纵贯、座面 14 高却 29 宽、扶手是 w6.4×h32 竖直细条、无椅腿
→ 窄直背 + 宽扁座 + 两根竖管 + 无腿 = **马桶**。

### ⭐ 配方（五件缺一不可）

1. **结构特征清单** —— 把该实物的识别件逐条列出
   例：王座 = ①宽靠背（≥座面宽 70%，顶部收拱/冠形）②靠背内装饰 ③外扩扶手（不是竖条）
   ④椅腿或侧板 ⑤座下台阶 ⑥正面厚度 ⑦重心偏高（靠背占高 55~60%）⑧左右镜像
2. **反面清单** —— 明写「什么样会变成别的东西」
   例：「窄直背 + 宽扁座 + 竖直细条扶手 + 无椅腿 = 马桶，四样一个都不许出现」
3. **基准图** —— 附上已认可作品，并写明共同语言（否则风格必然脱节）
4. **输出契约** —— 坐标范围 / **id 唯一前缀**（多份片段拼接时必须）/ 零渐变 / 无 `<svg>` 标签 / 文件路径
5. **执行顺序 + 强制落盘** —— 「第1步写A、确认落盘；第2步写B；第3步才回复」
   （实测有 agent 只回一句「我先落 A 案」就结束，文件根本没写）

### 出案后必做的检验

- **真实尺寸排一行**（手机 38px / 桌面 44px）—— 缩小后认不出就是废稿
- **纯黑剪影检验** —— 用 `feColorMatrix` 把图形 RGB 归零、保留 alpha，填黑还认得出才算过关
  （⚠️ 底盘不参与剪影，否则整盘变黑，检验失效）
