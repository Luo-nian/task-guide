## 0. 三条铁律（boss 三轮否掉后总结）

1. **徽章必须与等级名同义**（画实物意象），不许用抽象几何（圆点/菱形/六角）。
2. **"更高级"只靠线条粗细 / 层数 / 装饰件数 / 动画数量与速度递进**，
   **绝不靠加颜色**——多底色会把金色徽章吃掉（第三版就是死在这里）。
3. ⭐ **动效与光效本身是等级特权**：Lv.1–4 完全静止零光效，Lv.5 起才"活"。
   低等级的"静"本身就是高等级"亮"的对比。

颜色空间**全程只有两个色系**：近黑底（#1C1B19 → #050508）+ 金（#6E5413 → #FBF0CB）。

## 3. 动效与光效阶梯（等级特权）⭐

| 等级 | 动效 |
| --- | --- |
| **1–4** | **完全没有**（纯静态，无光晕、无流光、无旋转） |
| 5 | 徽章光晕呼吸（6s 一息，弱）+ 徽章核心微光 |
| 6 | ＋ 宝石闪光（高光 `r` + `opacity` 同步脉动）+ 边齿缓转（34s/圈）+ 进度条流光 |
| 7 | ＋ 卡面流光扫过（6.4s，扫 1.8s 停 4.6s）+ 星芒脉冲 + 双环反向旋转（30s / 27s） |
| 8 | ＋ 绕框跑光（13s 一圈，Lv.9 压到 9s、Lv.10 6.5s）+ 旋转加速（22s / 20s） |
| 9 | ＋ 绶带轻摆（±2°，6s）+ 顶冠明暗呼吸 |
| 10 | ＋ 星尘明灭 + 行星公转（4 轨道 16s/圈）+ 核心恒星脉动 + 全线提速（10s/12s/6.5s） |

所有动画**时长随等级收紧**（Lv.5 是 6s 一息，Lv.10 全部 1–4s），
所以高等级看起来"更有能量"，低等级"沉稳安静"。

## 4. 手机端落地要点（Compose）

- 等级卡画在 `Canvas` / `drawBehind` 里，按 `lv` 取上面三张表的开关值；
- 徽章用 `Path` 复现第 1 节意象（48×48 设计稿坐标系，中心 (24,24)，可绘制半径 ≤ 19）；
- **动画统一走 `rememberInfiniteTransition`**，`lv <= 4` 时**完全不创建 transition**
  （不要创建了再乘 0，会让低等级也在跑重组）；
- 光晕用 `Brush.radialGradient`，跑光用 `PathMeasure` 取周长 + `PathEffect.dashPathEffect`
  配 `animateFloat` 的 phase（对应 SVG 的 `stroke-dashoffset`）；
- 镶珠/边齿 = `PathEffect.dashPathEffect` 小点 + `rotate(phase)`。

## 6. 已验证的 SVG 高级技法（照抄即可）

| 效果 | 做法 |
| --- | --- |
| 绕框跑光 | 圆角矩形描边 `stroke-dasharray="段长 余长"` + 动画 `stroke-dashoffset` 走完整周长<br>周长 ≈ `2*(w+h) - 8r + 2πr`（292×164 r14 → **888**） |
| 钱币边齿 / 镶珠圈 | 圆或圆角矩形 + `stroke-dasharray` 小点（一个元素顶一圈珠子）<br>加 `animateTransform rotate` = 转动表圈 |
| 流光扫过 | 斜置 `<g transform="rotate(18,...)">` 内放窄亮带 rect，<br>`animateTransform type=translate` + `keyTimes` 留白（扫一下停一会儿） |
| 光晕呼吸 | 径向渐变圆 + `animate opacity`（不要动 r，会掉帧） |
| 宝石闪光 | 高光小圆同时动画 `r` 与 `opacity` |
| 行星公转 | 轨道组整体 `rotate`，核心恒星留在组外保持静止 |

### 8.3 ⭐ 动效实现：**必须用 CSS 关键帧，不要用 SMIL**

预览用的 inline SVG 渲染器会把 `<animate>` / `<animateTransform>` 这类 **SMIL 元素直接丢掉** ——
于是"做了动效"在 boss 眼里等于"没做"（已实测踩坑一次）。

```css
/* 正确：CSS 关键帧 */
.tw{animation-name:tw;animation-iteration-count:infinite;transform-box:fill-box;transform-origin:center}
@keyframes tw{0%,100%{opacity:.3}50%{opacity:1}}
.orb{animation:spin 22s linear infinite;transform-box:fill-box;transform-origin:center}
@keyframes spin{from{transform:rotate(0)}to{transform:rotate(360deg)}}
```

> 坑：CSS 里旋转/缩放 SVG 元素**必须同时写 `transform-box: fill-box` + `transform-origin: center`**，
> 否则默认绕用户坐标原点（0,0）转，整个图形会飞出画面。

### 12.1 ⭐「金银金属对」—— 水/浪类元素用银，不用金

`破浪骑士` 的浪如果用金色，会读成"钩子/飘带"而不是水。改用：

| 用途 | 色值 |
| --- | --- |
| 浪体 | `#D9DEE6`（银） |
| 浪花/泡沫 | `#F4F7FA`（浅银） |
| 金（盾） | `#E8CB7F` / 暗面 `#B8892B` / 高光 `#F7E7BB` |

金 + 银是纹章学里的**标准金属对**，既有水的质感，又不破坏"近黑 + 金"的卡面主调。
→ 以后凡遇"水、冰、月光"这类元素，**一律银系**，不要硬塞金色。

### 12.2 粒子提速参数（boss：「粒子移动的速度加快一点点」）

| 项 | v3 | **v4（现行）** |
| --- | --- | --- |
| 漂移周期 | 12–18s | **8–12s** |
| 明灭周期 | 4.6–7.4s | **3.4–5.4s** |
| 漂移位移 | `translate(-16px,-22px)` | **`translate(-20px,-27px)`**（幅度也加大，肉眼才看得出在动） |

### 12.3 ⭐ 流星「随机位置飞出」实现（CSS 变量 + JS 重掷）

CSS 关键帧里用**自定义属性**当参数，JS 在每次飞完后重掷：

```css
.sh{position:absolute;left:0;width:96px;height:1.6px;--rot:20deg;--dx:660px;--dy:240px;
    background:linear-gradient(90deg,rgba(255,246,220,0),#FFF6DC);opacity:0;
    animation:shoot 7s linear infinite 1.4s}
@keyframes shoot{
  0%,86%{opacity:0;transform:translate(-110px,0) rotate(var(--rot))}
  90%   {opacity:1}
  100%  {opacity:0;transform:translate(var(--dx),var(--dy)) rotate(var(--rot))}
}
```
```js
function reroll(el){
  var top = Math.round(Math.random()*72);            // 起点高度 0–72%
  var dir = 13 + Math.random()*25;                   // 角度 13°–38°
  var dx  = Math.round(640 + Math.random()*140);
  var dy  = Math.round(Math.tan(dir*Math.PI/180)*dx);
  el.style.top = top + '%';
  el.style.setProperty('--rot', dir.toFixed(1)+'deg');
  el.style.setProperty('--dx', dx+'px');
  el.style.setProperty('--dy', dy+'px');
}
el.addEventListener('animationiteration', function(){ reroll(el); });
```
> 要点：`--rot/--dx/--dy` 给好**默认值**，这样即使脚本没跑到，也有合理轨迹兜底（渐进增强）。
> 两条流星用**不同 duration（7s / 8.6s）与 delay**，永远不会同时同向飞出。

### 14.1 ⭐⭐ 核心教训：**元素画了 ≠ 看得出来**

前几版的通病：**元素识别度不足**。原因三条，逐条立规矩：

| 病 | 规矩 |
| --- | --- |
| 元素太小 / 被其他元素盖住 | **每个元素必须占够面积**：单元素短边 ≥ 徽章直径的 **35%**；被压在后面的元素，**两侧至少各露出 30%** 才画（否则等于没画） |
| 只用细线画，缩到 40px 就糊 | **元素轮廓线 ≥ 1.3 units**（按 -30~30 的坐标系）；关键识别线（花瓣分界、折痕、浪头卷曲）**≥ 1.5 units** |
| 同色系叠同色系，看不出层次 | 元素之间必须**有色差或明暗差**：主金 `#E8CB7F` / 暗金 `#B8892B` / 高光 `#F7E7BB` / **银 `#D9DEE6`** / **白 `#E7ECF2`** |

### 14.2 ⭐ 白/银三档：水、云、泡沫一律用白系，不用金
