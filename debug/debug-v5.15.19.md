### B-005　自动连接（S1–S3）真机未实测 ⏳

- **症状关键词**：自动连接 / 自动扫描 / 连不上 / 扫描设备 / mDNS / 换个 WiFi
- **现象**：代码已修，但 boss 尚未在真实网络（宿舍 WiFi）里验证「手机连上同一 WiFi → ≤10s 自动连上」
- **已试**：
  1. 常驻看门狗 + mDNS 自适应窗口（见上表）
  2. 副机 V2131A 无线调试验证的是 **S5–S7 状态显示**，**不是** S1–S3 自动发现（副机走的是 adb 直连 IP，绕过了 mDNS）
- **当前结论**：**自动扫描强依赖 mDNS 组播**。校园网/企业网（如 `10.200.37.x`）拦组播概率不低 → 有失败风险
- **已知限制**：
  - 手机息屏后 Android 侧 mDNS 广播停播（实测 `adb mdns services` 变空），亮屏恢复 —— 与桌面扫描逻辑无关
  - 若实测失败，手动点「扫描设备」仍应成功；手动也扫不到 → 手机端 `MdnsRegistrar` 被多播锁拒绝
- **下一步（boss 实测失败时的备选）**：
  1. 给手机设固定 IP（最省事，首选）
  2. 「按上次 IP + mDNS 双路尝试」策略
  3. 手动输入 IP 兜底入口
