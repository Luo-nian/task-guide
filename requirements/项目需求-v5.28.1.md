## 需求清单

1. **追踪误报根修**（boss：「自己看看我现在的手机画面再说你已经解决了」）
   - 现象：每日习惯「健身」（昨天打卡后 DB done=1，跨天折算只在读取层）今天点「追踪」
     被 v5.26.0"已完成任务不许追踪"校验拦下，而 v5.28.0 A3 弹窗把 **startTracking 的一切
     false 都误报成"名额已满"** → 1/3 显示已满。
   - 修：①`startTracking` 返回值 Boolean → `TrackStartResult`（OK / LIMIT_REACHED /
     ALREADY_DONE / NOT_FOUND）②daily 类任务 done=1 放行（每日打卡后第二天继续追踪是正常
     语义）③三处 UI（主页 HabitRow / TaskRow / 任务详情页）按结果分流，只有真·名额满才弹窗。
   - 验收：真机 tap「健身」追踪按钮 → 进入追踪（计数 1→2），无弹窗。✅ 已实测

2. **我的页：删掉问候语下面的分数行**（boss：「和身份卡之间要放一个分数？不好看」）
   - 「夜深了，历练学徒」下面那行金色「19 分」删掉——身份卡右侧本来就有 N / 下一级。
   - 验收：真机我的页无独立分数行。✅ 已实测

3. **习惯页没有入口**（boss：「哪里有习惯页？」）
   - `composable("habit")` 路由注册了但全项目无任何 navigate 调用 → v5.28.0 C1 补卡功能
     藏在一个进不去的死页面。
   - 修：「我的」页「习惯坚持」统计卡加 clickable + 「›」→ 进「每日任务」页。
   - 验收：真机点卡 → 每日任务页（打卡/补卡可见）。✅ 已实测
