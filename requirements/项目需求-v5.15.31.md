## 一、电脑端

### R1 关闭输入时弹出的「保存的信息」下拉
- 现象：输入昵称时弹出 WebView2 表单自动填充建议框（标题「保存的信息」+ 历史值「boss」）
- 处理：昵称输入框补 `autocomplete="off" autocorrect="off" spellcheck="false" name="tgNickEditBox"`（时间框原本已有）
- ⚠️ 若 HTML 侧关不掉，需在 Tauri 侧给 WebView2 加禁用 autofill 的 browser args（待验证）

### R2 删除「今日任务完成比例」小字
- 位置：今日进度卡的 `.pc-exp-hint`
- 处理：整行删除（进度条不再配说明文字）

### R3 昵称改「修改键」形式
- 原来：常态输入框 + 保存按钮 + 「回车也可保存」提示
- 现在：常态只显示昵称文字 + 一枚很小的「修改」键（10.5px）；点它才出输入框
- 新增 `#profileNickText` / `#profileNickEdit`；JS 加 `_nickEnterEdit` / `_nickExitEdit`；blur 兜底防「输入框挂着不退」

### R4 总览 / 今日 / 每日任务默认选中第一个任务
- 原实现只覆盖分类页，且 `render()` **没 await**（用的是上一轮 tasks 数据）
- 现在：回调改 async、`await render()`，统一走 `pickDefaultTask()`（追踪中 > 未完成 > 第一条；分类页只在同分类里挑）

### R5 设置界面排版重做
- ⭐ **修掉一个结构错**：「关于」分组被嵌在「连接与外观」分组**内部**（卡片套卡片）→ 已拆平
- 分组重排为：**外观 / 任务默认 / 提醒 / 追踪 / 连接 / 关于**
- 行距 9→11px、分组间距 14→18px、行首标签宽度统一 112px、按钮统一规格、说明小字右对齐
- ⚠️ 顺带发现：`.setting-row` 里「方式」与「手机端默认提醒方式」内容重复（本轮**保留元素只改标签**为「提醒方式」，避免断 JS 引用）

### R6 外观：白天 / 夜间 / 跟随系统
- 新增「外观」分组 + 分段控件（`.seg-row` / `.seg-btn`）
- 夜间配色：深墨褐底 `#14120E` + 鎏金描边 + 米白字（与手机端深色调一致）
- 实现：`data-theme` 挂 `<html>`；`[data-theme="dark"]` 覆盖 `:root` 变量 + body 背景层 + 硬编码暖白控件
- ⚠️ **主题不进 settings 同步通道**（设备本地偏好，同步会覆盖对端）→ 只存 `localStorage['taskbar.theme']`
- 跟随系统用 `matchMedia('(prefers-color-scheme: dark)')` 实时监听

### R7 每日任务刷新时间可改
- 新增设置项「每日任务刷新时间」（时 : 分 两个小框，复用 `.tbox`）
- 字段 `daily_refresh_time`（'HH:MM'，默认 '00:00'），与旧字段 `daily_refresh`(bool) 并存：
  bool 管**要不要**刷新，本字段管**几点**刷新
- 走 settings 同步通道（双端刷新口径要一致）
- ⚠️ **待办**：Rust 侧每日刷新定时逻辑还没接这个字段（当前仍是 0 点）
