## R35 · Lv.9 改名（推翻「天书」，重新思考）

boss：「天命传奇改的名字更是垃圾 九级要叫"天书"？**我们这个app是做什么的？等级本身是为了什么你想过没有？**」

### ⭐ 我之前的错
只想着「这个名字好不好画」，完全没想「它跟用户有什么关系」。

### ⭐ 重新确立的命名基准（写进守则第零节配套）

- **App 做什么**：任务管理。核心动词只有一个 —— **完成**。
- **等级为了什么**：把「坚持」这件抽象的事变成看得见的成长。用户看等级不是为了炫，是确认「**我这段时间没白过**」。
- **所以名字必须让用户感到**：「这是我一步一步做出来的」，而不是一个跟他无关的玄幻头衔。

### 六个候选（全部围绕「完成 / 坚持」）

| 候选 | 出处 | 咬合点 |
| --- | --- | --- |
| **不息者** ⭐ 推荐 | 《周易》「天行健，君子以自强不息」 | 「不息」= 从不停下，正是本 App 最想夸用户的品质 |
| 不辍者 | 日耕不辍 | 同上，字形略生僻 |
| 长明者 | 长明灯 | 灯不灭 = 你没停；但气势偏柔，压不住 8 级 |
| 万成者 | 万 + 成 | 直接对应「完成」动作 |
| 垒岳者 | 垒土成山 | 每完成一件事 = 垒一块石 |
| 登峰者 | 攀上绝顶 | 气势够，但 ⚠️ 与 Lv.4「星阶」思路撞车 |

**推荐理由**：① 只跟本 App 有关；② 承上启下（8 霸主=强大 / 9 不息=持久 / 10 传说=超脱，三种境界不重复）；③ 图形不撞（星核 + 不闭合光环）。

## R36 · 指挥子代理画实物的纪律（流程）

⭐ **教训**：让 AI 画「某一类实物」时，只给名字它会画错 —— 必须同时给：

1. **该实物的结构特征清单**（王座 = 靠背 + 座面 + 扶手 + 椅腿 + 台阶 + 正面对称 + 重心偏上）
2. **反面清单**（写成别的东西的拼装组合；例「窄直背 + 宽扁座 + 竖管 + 无腿 = 马桶」）
3. **已认可作品的基准图**（否则风格必脱节）
4. **输出契约**：坐标范围 / id 唯一前缀 / 零渐变 / 无 svg 标签 / 写文件路径
5. **强制先写文件**（有 agent 只回一句话就收工，文件没落盘）
