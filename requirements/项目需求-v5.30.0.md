## 一、Boss 原话（逐条）

1. 「我需要在手机端在主页加一个**下拉刷新**的功能，刷新过程中和电脑联系一下，进行**几次双端同步**。
   当然，我不希望这个过程中存在卡顿。刷新的同时还应该**检查一下通知权限** ——
   因为我已经打开了通知权限，两个手机都是，但是你还是在主页显示了那个权限未开启弹窗。」
2. 「我需要你在 next任务 里加一个**接口**，或是别的什么东西，只要 AI 一接触就可以**很容易地操控这个 app**，
   这样方便我可以让 AI 帮我进行**添加或完成任务**等操作。你自己研究，我要看到的只是成品。
   当然，AI 添加的任务也应该遵守**双端同步**的原则，手机也要同步增删减和追踪任务等等。」

## 二、R1 主页下拉刷新 + 同步 + 权限复查

| 子项 | 做法 |
| --- | --- |
| 下拉手势 | **自写轻量实现**（`ui/PullRefresh.kt`，约 150 行）。不用 material3 的 `PullToRefreshContainer`：项目锁 compose-bom 2024.02.00（material3 **1.2.0**），该 API 在该版本是实验态且 1.3 大改签名，升库会牵动 `TGColors` 那批依赖，风险不值当。 |
| 手感 | 阻尼 0.45（越拉越沉）、阈值 62dp、松手回弹动画、指示器跟手位移；三态文案：下拉同步 → 松开，与电脑同步 → 正在与电脑同步… |
| **与电脑联系几次** | `TaskViewModel.manualPullSync(rounds = 3)`：给所有已连接电脑端广播 `{"op":"syncnow"}` 共 3 轮（间隔 650ms），电脑端收到立刻 `full_sync`(拉) + `push_full`(推) —— **双向收敛**。 |
| 不卡顿 | 整条在调用方协程里跑（`rememberCoroutineScope`），只有 `delay`，不碰主线程；本机列表靠 Room Flow 自动刷新，**不做任何阻塞式重查**。 |
| 无电脑连接时 | 回一句人话「电脑端未连接 —— 已刷新本机数据」，不假装成功。 |
| **通知权限误报（真 bug，当场修）** | 根因：`Screens.kt` 的 `NotifPermBanner` 用 `remember { areNotificationsEnabled() }` —— **只在首次组合取值并永久缓存**。换装正式版后 Android 13+ 通知权限默认关闭，首次启动取到 `false`，之后 Boss 在系统里手动打开，横幅仍常驻。修：改 1.2s 轮询实时值（与本文件 `MissedBanner` 同一手法），首帧给 `true` 避免闪现。 |

## 三、R2 AI 控制接口（`/ai/*`）

**设计要点**（细节写在 `server/AiRoutes.kt` 顶部注释）：

1. **自描述**：`GET /ai/help`（免令牌）返回全部端点 + 字段 + 示例 → 「AI 一接触就会用」。
2. **令牌鉴权**：`X-AI-Token` 头或 `?token=`；令牌存设置项 `ai_token`，首次访问自动生成，
   手机端「设置 → AI 控制」可见可复制（与地址一起给 AI）。
3. ⭐ **写操作全部走 `TaskRepository`**（`createTask` / `completeTask` / `startTracking` / `addStep` …）：
   repo 每条写路径都带 `push_change` → AI 的改动**自动经 WS 推给电脑端**，
   与手机手动操作**完全同一条链路**。这是本接口与"直接改数据库"的根本区别。
4. 端点：`GET /ai/tasks?filter=today|all|tracking|deleted`、`POST /ai/tasks`（可带 steps）、
   `PATCH /ai/tasks/{uuid}`、`POST .../complete`、`POST .../undo`、`POST .../track`、
   `DELETE /ai/tasks/{uuid}`、`POST .../steps`、`POST /ai/steps/{uuid}/done`、
   `DELETE /ai/steps/{uuid}`、`POST /ai/sync`。
5. 追踪失败原因原样透传（`LIMIT_REACHED` / `ALREADY_DONE` / `NOT_FOUND` + 中文 reason），
   **不让 AI 猜**。
6. 配套交付：WorkBuddy 技能 `next-task-ai-control`（`~/.workbuddy/skills/`），
   以后任何会话里 AI 都能直接照着调。

### 桌面端配合改动（`desktop/src/sync.rs`）

WS 收到 `{"op":"syncnow"}` → 立刻 `full_sync` + `push_full`（最多 2 轮推送）。
**为什么必须改桌面端**：手机是服务器、电脑是客户端，手机本身**没有主动"连"电脑的能力**，
只能通过已建立的 WS 反向催桌面 —— 这条控制通道（`PULL_BUS`）与 `ChangeBus`（数据变更）**分开**，
避免控制消息被电脑端当变更写库。
