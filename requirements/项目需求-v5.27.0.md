## 背景与现状结论（已核实代码）

| 现状 | 位置 | 结论 |
| --- | --- | --- |
| 配对单密钥 | `AuthState`（Auth.kt）只存一个 `auth_secret`，`approve()` 生成新密钥直接覆盖 | **第二台客户端配对 = 第一台被踢**，协作第一改造点 |
| 无负责人 | `Task` 实体无 owner 字段 | 需迁移（boss 手机有真实数据，**迁移必须写并注册**） |
| 无变更记录 | `ChangeBus` 仅实时事件流（replay=256），重启失忆 | 需持久化新表 |
| 桌面端提醒 | 前端 JS 轮询 Rust `get_next_reminder`（SQL）后弹窗 | owner 过滤加在 **SQL 层**最干净，前端零改动 |
| 桌面端是唯一客户端 | 手机端无客户端角色 | 双手机协作（对等网）留下一版 |

## 需求清单

### A. 多客户端配对（手机端，核心改造）
- A1 新表 `paired_devices(device_id PK, name, master_hex, paired_at)`；Room v5→v6 迁移：旧 `auth_secret`+`paired_device` 迁成一行 legacy（device_id=''），**现有配对不失效**
- A2 `guard()`/`wsTokenOk()` 按 X-TB-Token 匹配任一设备密钥 → 通过并返回设备身份（变更记录的「谁」靠它）
- A3 `PairingState.approve()` 生成新密钥**新增一行**不再覆盖；device_id 从配对申请带上来
- A4 配对上限：免费 1 台（现状）／Pro 5 台；超限时配对页提示「多设备协作需要买断」
- A5 设置页「已配对设备」列表：名称+指纹+逐台解绑（删行即吊销该设备 token）

### B. 负责人字段（双端）
- B1 `tasks` 加 `owner TEXT NOT NULL DEFAULT ''`（存设备身份名，空=自己/全员）
- B2 手机端：Task 实体+编辑页「负责人」选择（本机名+已配对设备名，**Pro 专属控件**）+ 列表行负责人小标签
- B3 本机身份名：手机设置 `self_name`（默认「我的手机」）；桌面端=配对时 deviceName
- B4 桌面端：Rust Task struct + SQLite migrate `ALTER TABLE tasks ADD COLUMN owner` + 新建/编辑任务 SQL + `sync.rs` 全量与 `apply_change` 两处 INSERT 列都加 owner（**apply_change 现有列表漏 remind_ahead_min 的先例不能再犯**）

### C. 提醒路由「发到该收的人」（双端）
- C1 手机端 `rescheduleAll`：owner 非空且 ≠ 本机名 → 不排闹钟、不立即提醒
- C2 手机端 `fireNow` 兜底同判（防排程后 owner 被改）
- C3 桌面端 `get_next_reminder` SQL 加 `(owner IS NULL OR owner='' OR owner=本机名)`
- C4 v1 不限制操作权：看得到就能改（LWW 照旧），只路由提醒

### D. 变更记录（手机端记录+展示）
- D1 新表 `change_logs(id, task_uuid, who, action, detail, created_at)`，索引 task_uuid；**不参与同步/备份**
- D2 写入点：本地写路径（创建/更新/删除/完成/开始/停止追踪/打卡，who=self_name）+ `applyChange` 远端变更（who=来源设备名）
- D3 保留：每任务 ≤20 条，全局 ≤2000 条自动修剪
- D4 任务详情页「动态」时间线（谁·动作·时间）；桌面端 v1 不展示

### E. Pro 门槛
- E1 免费：配对上限 1 台、无负责人控件、无动态区（显示买断引导）
- E2 Pro（License.isPro 已有）：5 台配对 + 协作全开

### F. 验证（逐项实际验证，不收「应该好了」）
- F1 手机端 `assembleDebug --offline`（副本编译流程）+ 桌面端 `cargo build --release --offline`
- F2 真机：v5→v6 迁移不丢 boss 真实数据；owner 任务提醒 A/B（只响该响的设备）；动态区显示
- F3 多客户端实测：第二台客户端配对后第一台**不掉线**（旧版会踢）
- F4 git commit + push（push 失败按代理坑换直连/代理重试）
