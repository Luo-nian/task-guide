## R2 · 双端「身份位」统一：去头像（v5.22.1）

boss 原话：「**为什么手机端还有头像存在 我不是说不要头像了吗 还是说你觉得头像这个功能很好？那你在电脑端也加上啊 现在双端只有一端有头像是个问题**」

### 先查事实（不猜）
| 端 | 情况 |
| --- | --- |
| 电脑端 | 身份位早在 **v5.15.29 L4** 就改成了**等级徽章**；首页左上角只有一个**菱形徽记(L logo)**；`cropOverlay` 头像裁剪器**已无任何入口**（死 UI） |
| 手机端 | 首页左上角仍显示**自定义头像**：优先 `settings.avatar_img`（电脑端同步过来的照片 base64）→ 其次 `avatar_emoji` → 再兜底人形图标 |

→ 也就是：**同一个"身份位"，桌面端是徽章、手机端是照片**，这就是 boss 看到的不一致。

### 处置（按 boss「不要头像」的意思）
1. **手机端** `Screens.kt::AvatarFrame`：删掉「同步照片 / emoji / 头像占位」三条分支，
   改为 **`LevelEmblem(lv)`**（复用 `Emblem.kt` 里已有的等级徽章组件，24dp、关入场动画）。
   函数签名加 `lv: Int`，调用点传 `Levels.of(points).lv`。**App 内不再显示任何头像。**
2. **电脑端**：删掉 `index.html` 里整块死 UI `#cropOverlay`（头像裁剪器 v4.13.2）。
   ⚠️ 残留的 JS（`avatarGrid` / `avatarPicker` / `openCropper`）**保持不动** —— 其挂载容器已不存在，
   全部走 `getElementById` 空保护，属惰性代码；删它风险大于收益，已在本文件记录待清理。

### 未清理（记录在案）
- 手机端 `ui/AvatarCrop.kt`、`ui/AvatarSync.kt` 现**无调用方**（死文件）；
  `TaskViewModel.avatarImg`（observeSetting("avatar_img")）已无人消费。**未删**，避免牵动同步链路。
