## R2 · 免费版「同时追踪上限 = 1」生效（✅ 已完成）

`ui/TaskViewModel.kt`：

```kotlin
val trackLimit = combine(settingsTrackLimit, _isPro) { limit, pro ->
    if (pro) limit else License.FREE_TRACK_LIMIT      // 免费 1 / 买断用设置里的值
}
```

- **未买断** → 上限固定 **1**（不管设置里存的是多少）
- **已买断** → 用设置里的值（默认 3，可调 1~10）
- 设置页那个「更改」按钮：**未买断时点了给提示**「买断后可自由调上限；免费版同时追踪 1 个任务」

⚠️ 这条改的是**既有行为**：以前所有人上限默认 3，现在未激活 = 1。
追踪时的拦截逻辑（`Screens.kt:755` 那句 Toast）**不用动**，它读的就是 `vm.trackLimit`。
