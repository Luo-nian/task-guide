## 排查记录

### N4 / N7：同一个根因（已定位）⭐

主页用 `showPinSection` 控制"当次点追踪不立即置顶"（v5.15.21 P3 的产物），但**取消追踪也执行 `showPinSection = false`**：

```kotlin
onJustTracked = { showPinSection = false },
onJustStopped = { showPinSection = false })   // ← 元凶
```

于是取消一个追踪后：
- **置顶区整个消失**（`if (showPinSection && tracking.isNotEmpty())` 整块不渲染）
- `todo = tasks`（因为 showPinSection=false）→ 追踪任务**掉进普通分类分组**，失去分层
- 要等切页回来（backStackEntry 变化）才恢复

**修法**：把"当次不置顶"从**开关**改成**记 uuid**——
`justTrackedUuid` 只让"刚追踪的那一个"留在原位，其余追踪任务照常置顶；
**取消追踪完全不动置顶区**。回到主页时清空 `justTrackedUuid`。

### N8：主页分类条（已做）

删掉 `CategoryFilterRow` + `catFilter`（主页直接显示全部今日待办）；「所有任务」页的分类筛选保留。

### N11：涟漪闪烁（已定位）⭐

`TrackRippleKey` 的内圈呼吸用的是 `0.62f - 0.30f * phase` —— **锯齿波**：每轮 phase 从 1 突跳回 0，
alpha 也从 0.32 瞬间跳回 0.62 → **每 1.9s 多闪一下**，正是 boss 听到/看到的那个多出来的"11"。

**修法**：内圈改用**独立的 Reverse（往返）动画** `0.40f + 0.22f * breath`，两端连续不跳变；
外圈扩散周期 1900→1600ms，内圈呼吸 800ms 往返（= 1.6s 一个完整呼吸）→ **一个扩散对应一次完整呼吸，节奏均匀**。

> 通用教训：**用 `Restart` 相位驱动"往返型"视觉属性（透明度/明暗）必然产生跳变**；
> 只有"从无到有"的属性（如扩散半径 + 两端 alpha 都为 0）才适合 Restart。
