### P1 根因（已定位）

同一个「追踪中的任务」在电脑端有**两套分组渲染**：

| 位置 | 标题 | 结构 |
| --- | --- | --- |
| 侧边栏「追踪」页 `renderTrackView()`（app3.js:585） | 「**追踪中**」 | **没有 `.cg-body`** → 无浅金底 / 无描边 / 无下圆角，行直接贴在分组头下 |
| 今日待办置顶组 `renderTodayView()`（app3.js:629） | 「**正在追踪**」 | 有 `.cg-body` → 与其它分类块一致的「大框」 |

→ 于是：**标题用词不一致** + **有没有"大框"不一致**，在分类列表里看着就是"不统一"。
另外 `.cat-group-head { cursor: pointer }` 是全局的，不可收起的组也显示手型（点了没反应）。

**修法**：① 追踪页标题改「正在追踪」（与手机端、今日待办一致）；
② 补 `.cg-body` 容器；③ 不可点的分组头 `cursor: default`。

## 三、本版踩坑记录（写进规范）

1. ⭐⭐ **预览里的 SMIL 动画会被渲染器丢掉** → 用 `<animate>` 做的"星空动效/入场特效"，boss 那边看到的是**静态图**，
   等于"没做"。**以后所有 SVG 预览与实装一律用 CSS 关键帧。**
2. ⭐⭐ **徽章不能用手绘生物线条**（人、马）：圆头线条拼的形状放大会显糙、缩小会糊成团。
   **只用器物与几何，且必须左右完全镜像对称 + 两色金属 + 深色描边。**
3. **CSS 里旋转 SVG 元素必须写 `transform-box: fill-box` + `transform-origin: center`**，否则绕用户坐标原点转、图形飞出画面。
