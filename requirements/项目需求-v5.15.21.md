## 已定位真根因

### D5 · 侧边栏分类筛选后列表为空 【P0 BUG，boss 第二次反馈】

**根因（双重不一致）**：

1. **后端 SQL 与前端归类逻辑不一致**
   - 前端 `catOf(t)`：若 `category` 不在白名单 → **按 `type` 推断**
     （`habit→daily` / `goal→goal` / `repeat→time-limited` / `note|once→once`）
   - 后端 `lib.rs:1171`：`WHERE category=?1` —— **只精确匹配字段，无推断**

   **实测证据**（直查 `taskguide.db`）：
   | 任务 | category 字段 | type | 前端归类 | 后端 `WHERE category='time-limited'` |
   | --- | --- | --- | --- | --- |
   | 整理收信箱 | `工作`（自定义） | `repeat` | **time-limited** ✅ | **0 条** ❌ |
   | 生活类 2 条 | `生活` | `once` | once ✅ | 0 条 ❌ |

   → **总览能看到（前端推断），分类页看不到（后端查不到）** = boss 描述的 bug。

2. **前端缓存把"空结果/失败"永久固化**
   ```js
   function prefetchCatTasks(cat) {
     if (catTasks[cat]) return;                  // 空数组是 truthy → 永不重试
     ...catch(() => { catTasks[cat] = []; });    // 失败也缓存 []
   }
   // 消费端：arr = catList || tasks.filter(...)  // [] 是 truthy → 不回退
   ```

### P4 · 任务栏右侧动态元素消失

- `style.css:545-567` 定义了 `.ct-diamond` + `.cat-task.tracking .ct-diamond` / `.list-task.tracking .ct-diamond` + `@keyframes rippleBreath`（涟漪呼吸）
- **但 `app3.js` 中已无任何地方生成 `.ct-diamond` 元素**（grep 仅命中图标定义 `diamond:` 第 167 行）
- → CSS 空转，元素在某次重构（疑为 v5.15.18 P1 删行内按键）时被一并删掉

### P2 · 次数任务积分偏高

- 「次数任务」= `category==='once' && count > 1`（可重复完成，每次给分）
- 现规则 `RewardRules.forTask(type, priority)`：`once` 基础 8 + 优先级（中 +4）= **12 分/次**
- 可重复完成 → 累计过高，与单次型任务同分不合理

### P3 · 取消追踪当场挪位

- `app3.js:1287` 追踪侧已做保护：`_pinTracking = false;  // 当次不置顶`
- `app3.js:1291 untrackTask` **无对应保护** → 取消后任务立刻跳回分类区

## 修法

### D5（双保险）
1. **后端 `lib.rs:1171`**：SQL 改为与前端 `catOf` 等价 —— `category=?1` **OR**（`category` 不在白名单 **AND** type 推断 = ?1）
2. **前端 `app3.js:715`**：
   - `prefetchCatTasks`：只缓存**非空**结果；失败**不**写缓存（允许重试）
   - 消费端：`arr = (catList && catList.length) ? catList : tasks.filter(t => catOf(t) === nav)`（用 `catOf` 而非 `t.category`）

### P4
在任务行模板（`catTaskHtml` / `renderListView` 行）补回 `<span class="ct-diamond"></span>`，仅 tracking 时由 CSS 显示涟漪。

### P2
次数任务（`count > 1`）单独降分：基础分减半 + 优先级加成减半 → 中优先级由 12 → 6 分。

### P3
`untrackTask` 加 `_pinTracking = false`（与追踪侧对称）。
