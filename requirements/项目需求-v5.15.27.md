## 三、排查记录

### M7 真因：闹钟只在「重启手机」时恢复 —— 重装/强停后就再也不响 ⭐

`DailyReminderScheduler.restoreAll()` 只被 `BootReceiver`（BOOT_COMPLETED）调用。
而 AlarmManager 的闹钟在**重装 APK / 强行停止 / 被系统清理**后会全部丢失 →
不重启手机就永远不再触发，表现就是 boss 说的「这个功能好像没什么用了」。

**修法**：`TaskBarApp.onCreate` 里补一次 `restoreAll()` ——
只要打开过 App，起床/睡前提醒就一直是活的。同时在设置页把「**下次：今天/明天 07:30**」写出来，
一眼就能看出这功能是活的。

### M3 / M6 决定：直接去掉页面切换动画

- M3 体感「要等按键交互结束才弹出来」= 按键反馈（PressIcon 180ms 缩放）+ 页面转场（240ms）叠加；
- M6 方向语义（我的 ← 主页 → 追踪）已按 `MAIN_PAGE_ORDER` 做过一版，boss 仍不认可。

按 boss 的原话「不行你把页面切换去掉吧」→ **转场全部置 None（0ms）**，点下即切。
主页面带的**左右滑动手势保留**（那是手势，不是动画）。以后想恢复只需把 NavHost 的四个
transition 参数换回 `slideIntoContainer`。

### P5 真因：收起分组是「整页重渲染」 → 滚动被重置 + 闪一下 = 抖动 ⭐

```js
function toggleCatGroup(k) { ...; if (typeof render === 'function') render(); }   // ← 元凶
```
`render()` 会重建 `lvEl.innerHTML` → 滚动位置重置 + 整块重绘闪一下。

**修法**：给分组容器加 `data-cg="<key>"`，`toggleCatGroup` 改为
**就地切 `.collapsed` 类 + 换箭头字形**，完全不重渲染 → 不抖、不跳、不闪。

### M1 / P2 真因：底色太淡（电脑端右端只到 6% 透明度）

- 手机端 `SectionHeader` **完全没有底色**，只有一行文字 → 和页面背景同色；
- 电脑端 `.cat-group-head` 的渐变右端是 `rgba(232,203,127,0.06)` → 基本等于背景。

**修法**：手机端 = 主题色 13% 淡染 + 1dp 描边 + 9dp 圆角；
电脑端 = 渐变加深到 `0.55 → 0.22` + 补一圈 `rgba(154,123,26,.30)` 描边 + 圆角 8px。

### P4 真因：分组头图标只有 13px 且带浅描边，压在金色栏上看不见

**修法**：给 `.cat-group-head .ico` 一个 **20px 圆角方块** + 白色内描边 + 外阴影，
图标强制白色 → 一眼能认出是哪个分类。

### M4 做法（已按 boss 二次修订定稿）

**最终形态（boss 二次修订后）**：
- **卡头右侧**：常驻「取消追踪 / 完成」两个 22dp 圆键（展开、收起都一样）
- **卡片底部**：常驻一条把手 —— 展开态写「收起 ▾」、收起态写「展开 ▸」，**两状态同一字号 20sp**
- 卡框与主页追踪卡完全同款：`1.5dp + Azure(alpha 0.65) + 12dp 圆角`

→ 展开/收起只影响"中间那段步骤栏"的显隐，**键位不再跳来跳去**。

### M14 做法：分段容器（**不动 item 数量**）⭐

看似应该"一个分组 = 一个 item 里放个 Column"，但「所有任务」页的**滑动多选命中测试**是
`flatRows[item.index]` —— 一旦把多个任务塞进同一个 item，index 与 uuid 的对应关系就整段错位，
拖选会选中错行。

**改法**：保持**一任务一 item**，给同一分类的每条任务一个**共享淡色底**：
- 首条圆上角、末条圆下角、中间不圆；
- 行间距从 LazyColumn 的 `spacedBy(8.dp)` 挪进**容器内边距**（`Arrangement.Top` + 行内 bottom padding）；
- 于是相邻两行的淡色底首尾相接 = 视觉上连成一个大框，且 item 数量完全不变（命中测试零风险）。

分组标题同时也自带上下外边距（padding 在 `clip` 之外，不会把标题栏撑高）。
