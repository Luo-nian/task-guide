# 项目需求 v5.18.2（2026-09-19 深夜）

> boss：「所有任务里 我之前让你设计的滑动缩小搜索栏的成功了 但是**点击任务栏后恢复**这个功能没做出来」

## R1 · 修复：搜索框滑动压成细边后，点它不恢复

### 根因（读代码即可定位）
压缩态的实现是「外层 Box 高度动画到 18dp，**内部仍放着那个 56dp 的 OutlinedTextField**」，
再靠 `.alpha(0.25)` 把它淡出、`clip` 裁掉超出部分。

问题出在**点击派发顺序**：Compose 是「**子节点先吃事件**」——
那个仍在的输入框把 tap 消费掉并拿去聚焦，父级 Box 上的 `.clickable` 永远收不到事件。
所以表现就是「滑动能压缩，但点它没反应」。

### 修法
1. **压缩态不再渲染输入框**，只画一条细边（金色淡底 + 细边 + 左侧小放大镜），
   `clickable` 挂在细边本身上 → 点击必然命中
2. 聚焦改为**下一帧再做**：点击回调里恢复态的输入框还没被组合出来，
   直接 `focusRequester.requestFocus()` 会抛 `FocusRequester is not initialized`
   → 用 `needSearchFocus` 标记 + `LaunchedEffect`（副作用在组合应用之后执行，节点已存在）
3. **800ms 防抖**：用户可能在列表还在惯性滑动时点开，此时 `scrolling` 仍为 true，
   不加防抖会立刻又把它压回去（看起来还是"点了没反应"）

### 真机验证（adb 驱动，逐步截图）
1. 进入「所有任务」→ 搜索框展开态 ✅
2. 列表区上滑 → 搜索框压成细边（只剩左侧小放大镜）✅
3. **点细边** → 恢复原高 **且自动聚焦（键盘弹起、输入框呈聚焦态）** ✅
4. 无崩溃日志、App 进程存活 ✅
