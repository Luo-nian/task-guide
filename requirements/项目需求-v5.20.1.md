## R2 · 竞品分析：闪点清单（✅ 已完成，`docs/竞品分析-闪点清单.md`）

boss 提出「闪点清单」与我们重叠且做得不错，让我参考。

**结论摘要**：
- 它是**北京木叶科技**（公司团队、6 年迭代、App Store 4.8 分 2835 评价）的悬浮式清单，功能广度远超我们
- ⭐ **它的差评就是我们的机会**：用户抱怨「**索要通讯录 + 定位权限**」「**免费的月历后来变会员**」
  → 我们主打「**零账号、零云端、数据不出局域网**」+「**核心永久免费、一次买断**」
- 它是纯工具，我们多了**桌宠 / 等级 / 徽章 / 打卡**的情绪价值 → 定位「**更想打开的清单**」
- **值得抄（按性价比）**：滑动完成任务 → 手机桌面小部件 → 番茄钟 → 多提醒 → 四象限看板
- **明确不抄**：云同步 / 账号体系 / 任务共享（都要服务器 → 毁掉零成本与隐私卖点）
