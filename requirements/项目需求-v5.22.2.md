## R1 · 手机端夜间模式（boss：「手机端也要切换外观啊 夜间模式加进来」）

### 做法（关键取舍）
全 App 有 **518 处** `TGColors.X` 引用（分布在 9 个文件）。**没有逐个改**，而是把 `TGColors`
的每个属性从「固定 `Color`」改成 **getter 读当前调色板**，调色板存在 Compose 的 `mutableStateOf` 里：

```
object TGColors { val Card get() = p.Card; ... }   // p = if (夜间) TgNightPalette else TgLightPalette
```

于是所有读过 `TGColors.X` 的界面都**自动订阅**调色板 → 切主题时整屏重组，**引用处一行没改**。

### 组件
| 位置 | 内容 |
| --- | --- |
| `UiFoundation.kt` | `TgPalette` 数据类 + `TgLightPalette`（原值）+ `TgNightPalette`（新增）；`TgAppearance`（light/night/auto + prefs 读写 `ui_theme`）；`TGColorScheme` 改为按夜间取 `TGColorSchemeLight` / `TGColorSchemeNight`；`TGBackgroundBrush` 也随外观切 |
| `TaskGuideTheme` | 进 `MaterialTheme` **之前**先按「模式 + 系统深色」定下 `tgIsNightState`（写前判等，避免重组死循环） |
| `MainActivity` | `TgAppearance.load(this)` 进 UI 前恢复偏好 |
| `SettingsScreen` | 「用户名」下面新增**外观**卡片：白天 / 夜间 / 跟随系统（与电脑端同三个选项） |

### 夜间配色思路
**暖深咖底**（`#17120E` 系，不是纯黑，保住"纸 + 赤陶"气质）：卡片 `#261E18`、文字米白 `#F2E9DC`；
赤陶提亮到 `#E0714A` 保证深底可读；边框反过来用**亮赤陶 + alpha**；按钮上是**深字**（赤陶偏亮）。

### 验证
装机实测：设置页出现「外观」，切「夜间」后整屏变深咖、卡片与文字可读、FAB/追踪按钮提亮；
截图 `docs/assets/手机-外观-白天.png`、`手机-外观-夜间.png`、`手机-夜间-主页.png`；随后已还原为白天。

## R2 · 激励语扩容（boss：「留 甚至要更多。记住不要有ai味 可以参考名人名言」）

| 位置 | 原来 | 现在 |
| --- | --- | --- |
| 完成/升级弹层底部那句 | 4 句随机（"又清掉一件，节奏不错"…） | **`CELEBRATE_LINES` 18 句**：一半平实口语（"先做五分钟，果然有用""完成比完美容易"），一半**公有领域古典名句**（荀子「不积跬步，无以至千里」、老子「千里之行，始于足下」、荀子「锲而不舍，金石可镂」、韩愈「业精于勤，荒于嬉」、王之涣「欲穷千里目，更上一层楼」、《周易》「天行健，君子以自强不息」） |
| 主页「今日全部完成」 | 1 句 `"今天的任务都完成了"` | **5 句轮换**，按**当天**（`DAY_OF_YEAR`）取模 → 同一天内不跳字，第二天换一句 |

取舍标准（写在代码注释里）：**短**（弹层空间小）、**不装**（不写"让…有成就感"这类 AI 味话）、
名句只收**出处可考**的，不瞎挂名字。

## R4 · 电脑端分类导航收拢（boss：「可以」）

**顶层从 8 个变 5 个**：总览 / 今日 / 追踪 / **所有任务** / 历史任务。
四类任务（每日·目标·限时·次数）收进「所有任务」一组：
- 默认**收起**，点展开；展开状态记 `localStorage`（刷新后保持）
- 当前就在四类之一时，`renderSideNav()` 会**自动展开**该组，免得看不到自己在哪
- 分组头不是视图 → 点击事件里加了守卫（否则 `nav` 被写成 `undefined`，会把渲染搞坏）

验证（CDP 实测）：顶层 5 个 + 组内 4 个；默认收起 ✅；点击展开 ✅；组内四项文字正确 ✅

## R5 · 按体验测试报告修的两个高价值问题

| # | 问题（来源） | 修法 |
| --- | --- | --- |
| 1 | **任务数据 + 配对密钥会被系统云备份带走**（程序员报告）：`allowBackup="true"` 且无备份规则，而 `auth_secret` 与任务同库 → 与「数据不过云」的宣称直接冲突 | `allowBackup="false"` + 新增 `res/xml/data_extraction_rules.xml`（云备份与换机迁移**全排除**） |
| 2 | **每日型提醒响过一次就再也不排下一次**（大学生·一个月报告）：唯一排程入口是冷启动/开机 → 只有天天打开 App 的人才有第二天提醒（正好解释"有两天没响"） | `ReminderAlarmReceiver` 触发后补排一次 `rescheduleAll` |

验证：两端编译通过；手机端装机冒烟（启动正常、`crash.log` 0 行）。
