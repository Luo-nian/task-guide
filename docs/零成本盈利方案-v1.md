---

## 一句话结论

**能到 ¥0。** 你不需要买域名、不需要服务器、不需要上架、不需要软著和备案 ——
**那些只在"走应用商店"这条路上才是必需的。**

---

## 一、为什么能到 ¥0：你这 App 天生不需要服务器

关键事实：**手机就是服务端**（Ktor 跑在手机上），桌面端是客户端。

于是三件最贵的事**自动消失**：

| 通常要花的 | 为什么你不用花 |
| --- | --- |
| 云服务器（¥60–100/月） | 没有云端，数据在你手机里 |
| ICP / APP 备案（约 2 周） | 备案管的是"境内服务器对外提供互联网信息服务" |
| 软著（60 天）+ 商店实名 | 那是"上架商店"的前置条件，直发安装包不需要 |

**会员激活也不需要后端** → 用**离线签名授权码**（客户端内置公钥，验签即解锁）。

## 三、零成本方案的四根支柱

1. **分发**：GitHub Releases（免费、无限流量）放 `exe` + `APK`，配一个 GitHub Pages 官网（免费）
2. **收款**：**爱发电**（国内，个人可注册，抽 6%）／**Ko-fi**（海外，抽 5%）／**Gumroad**（海外买断，抽 10%）
3. **激活**：**离线签名授权码**（买断制）—— 我本地生成，你发货
4. **推广**：酷安 / V2EX / 少数派 / 小红书 / B站（不花钱，但要你出人）

## 七、技术实现（我这边，¥0）

1. **离线签名授权码**
   私钥签 `版本|签发日|序号`，客户端内置公钥验签 → **无需服务器、无需联网**
   （基础已有：v5.17 我自研的那套 ChaCha20 + HMAC-SHA256 体系可直接复用，或换 Ed25519）
2. **授权码输入入口**：桌面端「关于」区块 + 手机端设置页
3. **免费限制落地**：追踪上限走现成的 `track_limit`（默认 3 → 免费 1）；导出功能加一道判断
4. **授权码生成器**：我本地一条命令出一批（你发货时用）
5. **官网**：GitHub Pages 静态页（下载按钮 + 收款二维码 + 怎么激活）

## 八、代价（诚实说）

1. ⚠️ **没有商店的自然流量** —— 得靠你自己去发帖推广。这是这条路**唯一真正的成本：时间和脸皮**
2. Android 直装要用户开「未知来源」，转化会打折 → 走酷安 / 群链接会好很多
3. 买断授权码**无法远程吊销**（只能靠内置黑名单兜底）
4. 不注册商标 = 没有品牌保护（你现在也确实不需要）
5. ⚠️ **个人收款码别用于经营收款**（有合规风险、可能被限制）→ 用爱发电 / Ko-fi 这类平台
