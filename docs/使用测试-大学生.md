## 1. 第一印象

暖米色 + 金，干净没广告位，第一眼我信它"不联网也能用"。打动我的是不注册、不上云、打勾涨经验——我弃掉的待办 App 全死在"先登录、等云同步"。
但电脑端同屏「今日待办 1 项未完成」和「今日剩余 0 项 / 进度 0/0」自相矛盾，加上顶栏两个没字的图标——**"算得准不准"最容易让我卸载**。

## 2. 使用场景走查

**① 早八前（床上 7:20）** 开 App 看今日任务 → 一条任务、大绿勾，清楚。但想设「提前 20 分钟提醒」**找不到地方**；设了 19:00 提醒到点不响，App 也不解释（问题 2、4）。

**② 图书馆记临时任务** 点「+」→ 填标题 → 保存 → 回首页，顺。但提醒默认「不提醒」（电脑-改后-新建任务.png），随手记的**记了等于没记**。

**③ 上完课标完成** 点绿勾 → 积分弹层即时反馈，这是我留下的理由。

**④ 周末第一次开电脑** 看到「1 项未完成」旁边写「今日剩余 0 项」，我先怀疑"没同步过来"，切两次才确认是它算错（问题 1）。

**⑤ 想备份/换手机** 导出只弹一条 2 秒 toast + 一长串路径，文件管理器里**点不进 Android/data**【推测，SettingsScreen.kt:915-918】；想恢复？**全 App 没有"导入"入口**（问题 3）。

看不到的：打开要等几秒、真机提醒响不响、断网多久自动连回。

## 4. 我最想要的 3 个功能

1. **本地"一键换机"闭环**：导出到我能找到的地方（下载/分享）+ 能选文件导回来。纯本地不上云，但真能按住我"怕数据丢"。
2. **周几重复（课程表式）**：我要「周一三五」，现在只能"每天"。
3. **断签保护/补打卡**：忘一次就清零，第二次就不敢打开了。

## 5. 会不会买「完整版」

**会买，但条件明确，且不为它的卖点买。**
唯一真卡我的是**同时追踪只能 1 个**（`License.kt:46`，SettingsScreen.kt:446 也这么写）——追 3 门课就顶住。
"一次买断、永久有效、不用联网"正对我 WiFi 烂、又不想给账号的脾气。
但「导出备份」导出来拿不到也导不回去（问题 3）、「外观主题」手机没入口（问题 9），这两条不算理由；**App 里看不到价格**，要跳爱发电——**≥20 元先不买，≤10 元当场买**。
