# 使用测试·孕妇（28 岁，孕 7 月，上班，易焦虑，常单手）

## 1 第一印象
装上第一眼觉得"完成涨经验/等级"挺可爱，但四类任务叫"每日/目标/限时/次数"，我真不知道**一次性产检该点哪个**。建完三周后的产检，主页立刻看不见它了，我当场慌了一下是不是没存上。

## 2 一个月时间线
- **第1天**：按提示建了第一次产检（选"限时任务"设截止时间）。松口气，但打字时另一只手一直扶腰，够顶部的"返回/保存"有点费劲。
- **第3天**：漏设"补铁"提醒——每天提醒时间那栏我以为默认就有，没点开就以为设好了。
- **第1周末**：想按孕周把整套产检+孕妇课一次性排好，发现只能一条条手建，没有模板；"每周三孕妇课"现在能正确只在周三提醒（这点变好了）。
- **第2周**：产检**改期**。改完时间旧提醒没再响（这点修好了，安心）。
- **第3周**：试"每天数胎动 3 次"。第一天能点 3 次完成，**第二天起这条既不再提醒、点完成也没反应——等于废了**。
- **第1月末**：想回看一个月、让老公也看产检表。导出备份找不到文件（落在 Android/data 进不去），也没导入；老公"一起看"只能自己装电脑端配对，还怕我俩改同一条互相覆盖。

## 4 我最想要的 3 个功能
1. **产检/预约"提前1天、提前3天"提醒**（现在只有到点一次，错过即真错过）。
2. **按孕周批量建计划模板** + 未来任务在主页有"即将到来"入口，别让未来的产检从眼前消失。
3. **家人"只读共看"**：老公扫码就能看我的产检日历，不能误改我的数据。

## 5 会不会买断，为什么
大概率会买。我怕漏事、又常单手操作，最需要的就是"提醒真的靠谱 + 数据别丢"——把完整版当"给我和宝宝的关键事项上保险"划算。但前提是：先把**产检提前提醒**做出来、加上**导入/换机不丢**、给老公一个**只看不改**的入口；这三点不做，买断我也会犹豫。
