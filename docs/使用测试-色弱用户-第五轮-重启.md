# 使用测试 · 色弱用户 · 第五轮（重启）

### 1 我是谁 / 半年一句话
30 岁男，红绿色弱，设计/印刷从业者，对颜色敏感却不敢信。半年中段我重装了 next任务（无任何旧记忆，从零开始），图它"不上云 + 锁屏隐藏任务名"合我客户保密；靠文字标签和左滑硬是把颜色绕开，用到半年末。

### 2 时间线
**第1周（重装）**：半年中段重新装回，图它"不注册 + 锁屏隐藏任务名"（印刷稿名不该亮锁屏，默认开我很满意）。¥8 再买断。这次我学乖：每个任务必写类型文字，不指望看色。
**第1月**：重新养"连续天数"，健身又连上。发现高/中优先级红棱仍分不清，但这次一律用文字标签+排序，压根不看色，没再误。
**第3月**：校色排期密集，靠"提前提醒"文字(提前30分)守 deadline，没掉球。但日历忙闲仍看不清，直接弃用日历视图。
**第6月**：用到半年末。桌宠升到 Lv.7，习惯全在。颜色对我只是"装饰"，信息全靠字与形——它算用顺了，只是永远绕开颜色。

### 5 结论
重装后我不再信颜色，改用文字标签+排序+左滑+锁屏隐藏+桌宠升级，硬绕过了色弱墙，用到半年末。它救回我的健身连续性和校色 deadline。但"状态靠颜色说话"对色弱仍是硬伤：只要补字形/角标/文字第二通道，我就能放心把颜色当装饰而不是信息。
