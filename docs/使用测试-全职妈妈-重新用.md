# 使用测试 · 全职妈妈 · 重新用（v5.23.0）

## 1 重装后第一印象

重装打开是一片空白，连「引导建第一个任务」都没有，像第一次用。设置里只有「导出备份」、没有「导入」——旧机已摔，导出文件还在旧机里，等于没用。买断的「完整版」也变回未点亮。

## 2 时间线（7 点）

- **换机当天**：想找回旧数据 → 设置只有导出、无导入；旧机坏 → 全丢。无法恢复（最高级）。
- **第 1 天**：手动重建家务清单（接送/买菜/缴费/吃药） → 逐条建+设提醒，约 20–30 分钟；无模板/快速建。
- **第 3 天**：提醒准不准 → 依赖 AlarmManager+电池白名单，被冻结时可能不响；单手抱娃中点开被打断，输入内容丢失（无草稿）。
- **第 1 周末**：再连家里电脑 → 需重新配对（`paired_device` 空），在设置页停留点允许即可，有摩擦但可行。
- **第 2 周**：老用户全归零 → 连续天数、等级、徽章全从 0，无「老用户」识别或安抚。
- **第 3 周**：买断码还在吗 → 完整版显示未点亮；激活随重装丢失，需重新粘贴授权码（没存码则权益永久丢）。
- **第 4 周**：还愿重来吗 → 基础清单免费还能忍；但重建一个月+重买断，意愿低。

## 5 还会不会再用 / 会不会买断

基础清单免费、手机端能用，我会先凑合用。但**换机数据全丢+无导入+买断激活丢失**这三点已踩到最高级红线——它们不是体验瑕疵，是「重新用」场景下产品不可用。除非加上「导入备份」和「授权码可找回/重新认领」，否则**不会买断**，且大概率用一阵就换更稳的同类 App。
