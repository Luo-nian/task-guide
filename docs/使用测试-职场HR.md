# 使用测试 · 职场 HR 视角（一个月）

> 被测：**next任务**（手机端 + 电脑端，个人开发者作品）。
> 测试者设定：28 岁女，200 人公司 HR（招聘 + 考勤 + 员工关系），**电脑是主力**（Win 笔记本，每天 8 小时），手机随身第二屏。同时跟进几十个候选人、多批次面试、月度考勤结算。最烦「信息找不到」「改一条要翻半天」。
> 手段限制：**只看截图与源码，没有实机点击、没碰手机**。能确证的标【已核实】+文件:行号，其余标【推测】，看不出来的一律写「看不到」。
> 本轮不重复提：电脑端分类导航收拢、手机端「阅览方式」措辞、手机端夜间模式。

---

## 1. 第一印象（三句）

长得舒服、打开就知道「今天还有几件」，这是我愿意为它付钱的那类工具；但它默认我只有三五个任务——**我的量级是几十个、成批出现、且必须一眼分清谁今天到期**。第一眼最刺的是电脑端首页三处数字互相打架（「1 项未完成 / 0 完成 / 剩余 0 项」同屏，见 `电脑-改后-首页.png`），我立刻不敢信这块面板了。

## 4. 我最想要的 3 个功能

1. **电脑端搜索 + 批量改（多选 + 批量改截止时间 + 批量完成）**。我每天的动作就是「这一批人一起往后挪两天」，没有它，量一大这软件就只能当便签用。
2. **「批次 / 分组」这一层**。让我能给一组任务挂「0312 批次-招聘」，按批折叠、按批筛选、按批一次改完，而不是靠标题里的方括号自救。
3. **电脑端真的会响的到点提醒**（含提前量）。面试不能靠手机在抽屉里震一下；顺便把「仅电脑端」这个选项修成它字面上的意思。

## 5. 会不会买断，为什么

**会买，但会边用边骂，而且现在这版我只肯出最低档。**

理由：它解决了我最核心的一件事——打开电脑就知道今天有什么、完成有正反馈，界面不吵，值得为效率付费（¥5~12 对我是零钱）。但买断的理由不该是「解封同时追踪」：我在电脑上追 5 个人本来就不花一分钱（问题 5），只有手机上被卡 1 个——买断收益落在我的**副设备**上，这很别扭。

真正拦住我给高价的，是三件「花钱也买不到」的事：电脑端没有到点提醒（问题 3）、没有批量与搜索（问题 8/9）、备份只能导不能回（问题 10）。我这种岗位最怕的不是功能少，是**改错一条要翻半天**和**数据搬不走**。这三条补齐，我会当场买最高档并推荐给同组的招聘同事——我们三个人加起来就是三份考勤结算。
