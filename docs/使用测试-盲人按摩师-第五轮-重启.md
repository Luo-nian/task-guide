# 使用测试 · 盲人按摩师（全盲）· 第五轮（重启）

### 1 我是谁 / 半年一句话
35 岁男，全盲按摩师，手机全靠 TalkBack 听 + 手势。上半年先装 next任务 用了约三个月后卸载；重装一次（完全不记得之前怎么用）从零用到半年末，记吃药、顾客、社保、残联活动，靠电脑端桌宠兜底删任务、靠关掉"锁屏隐藏"让提醒能念出名字。

### 2 时间线
**第1周（重装后）**：错过残联班车后改回系统日历，有回又记错顾客时间，想起这 App 连续打卡真让我吃了 19 天药，于是重装。像第一次用，立刻又撞：左滑删任务找不到（Screens.kt:343）、"提前提醒"小钟不念（Screens.kt:867）。
**第1月（重装后）**：重建吃药+顾客清单。请同行朋友帮忙看屏，才发现设置里"锁屏隐藏任务名"是开着的——关掉后（SettingsScreen.kt:377 Switch），锁屏提醒终于念出"社保缴费今天到期"，这对我才是真救命。连续天数从 0 重来（上次 19 天随卸载没了，那次没导出备份）。
**第3月（重装后）**：已摸索出用电脑端（桌面挂件/桌宠）删任务最稳，手机端只记和听。批量清过期仍靠电脑端（Screens.kt:1722 手势读屏做不了）。这期间朋友告诉我有"导出/导入备份"，开始定期导出到本地，怕再丢。
**第6月（重装后）**：重装后约满三个月，用满半年。整体能撑住，但无障碍缺口没变：图标缺 contentDescription、左滑手势对读屏不可用、提醒状态不念。我靠"电脑端删 + 关锁屏隐藏 + 听任务名"绕开了，没再卸载。
