# 使用测试 · 消防员（国家队） · 第五轮 · 重启

## 1 我是谁 / 半年一句话
29 岁国家队消防员。前三个月因驻勤摸不到手机、误了鉴定报名删了；6 月底我又装回 next任务，像从没用过一样从零来——这回多了锁屏隐藏、导入备份、提前提醒，驻勤手机限时还是没解决，但我硬着头皮用到了半年末。

## 2 时间线
### 第1周（7 月初，重装后）
当全新用户重装。重建汇款/复检/装备保养。注意到通知栏只写"你有任务到点了"——后来懂是"锁屏隐藏"（默认开），驻勤同事借手机也看不到我记的私事，反而安心。

### 第1月（8 月）
用上"提前 1 天＋提前 1 小时"双保险。但驻勤手机限时照旧：8 月复检提醒在出警日响，还是摸不到。日历 0 点翻页——我习惯夜里保养装备，23:50 打卡 0:10 又显没做，懒得管。

### 第3月（9 月≈半年末）
站里统一安全擦机前，用"导出备份"存了 json 到微信文件，重装后"导入备份"恢复，数据没丢——比上半年强。但"同时追踪 1 个"仍卡：汇款/复检/鉴定/保养想同时盯，免费只能追 1 个。连续天数按 0 点，跨夜常断。

### 第6月（半年末）
用到现在没再删。桌宠/升级在电脑，驻勤电脑不开，手机上完成靠那下震动凑合。睡眠时段静音依旧没有，我把重要提醒都设成"提前 1 天＋提前 1 小时"并嘱老婆兜底。
