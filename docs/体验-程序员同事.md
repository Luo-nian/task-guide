# 体验 · 程序员同事视角（前端 / 同组 1 个月）

> 被测：**next任务**；设定：30 男，前端，做过小工具产品，与 28 岁后端同事**同组共用一份数据**管需求节点/上线窗口/值班。视角偏**键盘效率、界面手感、技术信任**。只看了截图与源码，未真点；不能确证的标【推测】。

## 1. 第一印象（≤3 句）
架构我信（不联网、手机当服），但**交互是"鼠标点出来的"，不是"键盘流出来的"**；对一天几十条任务的效率用户，它更像"能用的玩具"而非"趁手的工具"。第一眼最扎眼的是整页右键被吞、列表行点不进去也敲不动。

## 2. 我的 5 个使用场景
- **晨会前批量收口**：想把昨晚记的 8 条"待跟"批量标完成 → 行内无按钮、无多选，得逐条进详情点完成。**卡**：两步 × N，效率低。
- **写代码时顺手记需求**：手在键盘上，想 `Ctrl+Shift+A` 唤起快记 → **没有任何全局热键**（app3.js:1319/2867 仅 ESC/Enter），只能摸鼠标点 FAB→填弹窗→选类型。**卡**：高频捕获路径最慢。
- **值班盯一条限时任务**：想常驻置顶当副屏 → `lib.rs:979` 有 `top` 命令但 UI 未见开关；关闭=托盘（lib.rs:2060，好评）。**卡**：置顶能力"有但找不到"。
- **和同事同改一条上线清单**：他改标题我改优先级，重连后一方被静默吞（同事已核实 LWW）。**卡**：冲突不可见，互不信任。
- **月底想导出团队备份**：桌面端零备份/导出（同事 A4 已核实）。**卡**：托付感崩。

## 4. ⭐ 颠覆性建议（≥3）
- **D1 · 重做成交互「键盘优先」**：弃"点 FAB→弹窗"范式，全局热键唤起 quick-add，输入"明早9点 提交周报 #工作"自动解析类型/时间/标签；列表 ↑↓ 聚焦、Space 完成、E 编辑、Del 删。替代方案：命令面板（Cmd+K 风）。
- **D2 · 桌宠升级为「置顶副屏效率终端」**：常驻置顶 + 全局热键 + 键盘流，把被删的行内动作键以"高效模式"交还列表，而非藏进详情页。
- **D3 · 团队共用补「归属 + 冲突可解释」**：加 owner 字段与按人视图；冲突显式弹"X 改了 Y，你的被覆盖"，让共用变飞轮而非负担。
- **D4 · 恢复列表行右键情境菜单**（替代全局禁用），提供复制/完成/追踪/委派。

## 5. ⭐ 定律应用表（≥6）
| 定律 | 在 App 上的体现 | 建议 |
| --- | --- | --- |
| 二八法则 | 80% 操作是"加/完成/看今日"，却主打详情深度+游戏化，快路径缺失 | 把 20% 高频动作做成零摩擦热键 |
| 福格 B=MAP | 完成有动机（经验）但能力门槛高（进详情两步）、触发弱（无热键） | 加全局热键与置顶触发，降能力门槛 |
| 木桶定律 | 数据可恢复性是信任短板，其他再花哨也托不住 | 先补导入/桌面备份/冲突可见 |
| 损失厌恶 | 最怕"被改丢/没了"，静默冲突+无备份放大损失感 | 冲突提示 + 本地自动备份 |
| 选择悖论 | 提醒方式/范围/提前/强度堆叠数十选项，效率与新手都晕 | 预设档位，进阶折叠 |
| 峰终定律 | "全完成"有祝福（好），"出错"终点静默无反馈 | 给失败终点明确提示 |
| Kano | 不联网是兴奋点（反向期望），键盘/批量是缺失的魅力属性 | 补魅力属性增效留存 |
| 现状偏差 | 老板因"误触"删行内键，效率用户却要它 | 设置开关保留两种模式，别锁死 |
| 宜家效应 | 自己 JSON 导步骤、自配键可提留存 | 开放更多"自己搭" |
| 网络效应/飞轮 | 两人共用本可互促，缺归属/可见冲突变负担 | 补归属与可见性成飞轮 |

## 6. 会不会推荐 / 会不会买断
**会买断**（¥5~12 便宜，无云架构加分），**只当个人副屏提醒，不当团队主力**。会推荐给"也想要无云清单"的同事；**不推荐给"团队共用"场景**——除非补键盘流 + 恢复 + 冲突可见。转正清单：全局热键/键盘导航 → 桌面备份导入 → 冲突 `(戳,设备号)` 可见 → 行内快操作开关。
