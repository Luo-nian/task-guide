## 1. 一个月时间线

**第 1 天** 弹通知权限，我点了"不允许"，App 再没提过这事（MainActivity.kt:82-87）。想追第 2 门课被拦，提示让我"去设置调高上限"，设置里点「更改」只回「买断后可自由调上限」（Screens.kt:361 / SettingsScreen.kt:388）——**把我支进死路**（问题 7）。

**第 3 天** 昨天的作业自动归档成「逾期未完成」（Database.kt:100），今日列表干净。我点了「恢复」被扣分、**等级静默退一级**（问题 2）——第一次觉得"分是不是白干了"。

**第 1 个周末** 只在电脑前有空整理：电脑端是流水账、手机端是日历，**两边翻法不是一套**（问题 9）。

**第 2 周** 忘打一次卡 → 连续天数**直接归零、还不能补卡**（TaskRepository.kt:398）→ 看到"0 天"比丢分难受。等级约 30 分/天，两周 200 上下 → Lv.3~4。

**第 3 周** 这周电脑用得多，进度仍 0/0（上一份问题 1）；断网用热点能连回来。有两天提醒没响：每日型提醒只在冷启动/开机时重排（问题 4）。

**第 1 个月末** 翻月后清单还锚在"今天"（问题 8）；历史 90 条上下、手机端没有搜索（问题 6）；导出备份仍取不回（上一份问题 3）。月末约 900 分 → Lv.6，第 4 周起明显变慢、升级只换名字和徽章 → 开始认真想买断。

看不到的：真机上一个月里到底有几天没响、耗电与发热——**我看不到**。

## 3. 一个月后我还留不留在手机上？

**留。** 它是唯一一个不用登录、数据在本地、打勾就有反馈的，一个月里真接住了我的作业和两个习惯。
但有两条底线：**提醒连着几天不响**，或**整理一次历史就掉级**——任一条成真我就卸，这正是我上次弃 App 的原因。

## 4. 我会在第几天、因为什么掏钱买断

**第 1~2 天心动但不买**：想追第二门课就撞上限（License.kt:46 免费 1 个），可提示把我支进设置绕圈（问题 7），我会先"那就只追一个"。
**真正掏钱的时点在第 3 周末**：想追第 3 门课、等级第 4 周变慢没盼头、历史开始要批量管，三件事一起到，这是付费意愿最高的窗口。
**卡住的**：App 里看不到价格，得跳爱发电；"导出备份"我导出来拿不到也导不回去、"外观主题"手机没入口（上一份问题 3、9）→ 我买的其实不是功能，是**想支持一个不逼我注册的个人开发者**。
结论不变：**≤10 元当场买，≥20 元先扛着**——但窗口就在第 3~4 周，拖过一个月我大概就不想了。
