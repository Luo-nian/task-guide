# 使用测试 · 初三男生（14 岁）

> 14 岁初三。旧安卓机（偶尔卡），父母不定期翻手机。晚自习后、课间、关灯躺床上用。测试期一个月。

### 1. 第一印象

等级 / 积分 / 连续天数我一眼就懂，是真愿意每天打开。但第一天我在主页愣了两分钟：只有一行「还没有任务 / 点右下角加号」，点进去第一行却写「标题 *」；设置也不在主页，翻到「我的」才找到。

### 2. 一个月时间线

**第 1 天｜安装、乱点**
加了「健身」「背单词」。保存后直接跳回主页，没有"已建好"提示。我把「目标」的截止开关关掉后，整块提醒设置消失了，不知道它去哪了。顶栏后面那个小点绿过也变淡过，猜不出是什么。

**第 3 天｜开始有遗留**
昨天没点完的「背单词」睡一觉又回到今日栏，没人说"昨天欠了一次"，只有日历里藏一条灰色"未完成"。行尾两个圆按钮（靶心、对勾）没字，我点错一次点成了追踪。点完成后弹一整屏深蓝遮罩 2.4 秒，得拍屏幕才关；一天六七条就被拦六七次。

**第 1 个周末｜批量整理 + 被家长看到**
三个同名的「背单词」，列表里只有名字，分不出哪个是哪个。长按多选删掉重复的，底部滑出"撤销"，这个我喜欢；但确认框写「两端一起移除」，我没电脑端，犹豫了。家长翻了半分钟手机，主页就是全部任务，「我的」里还有等级——没有任何锁。

**第 2 周｜断卡、列表变长**
跑步连了 5 天，第 6 天没点。第二天那行直接变成「连续 1 天」，没有任何"你断了"的提示，就悄悄归零。等级卡 Lv.1 历练学徒 9/50。任务涨到十几条。旧手机卡不卡我没法确认（看不到实机）。

**第 3 周｜关灯用、误触、同学**
关灯切"夜间"，底色变深咖不难受了，但系统状态栏还是白的，看时间特别刺眼。上课手机在裤兜，主页能左右滑动切页，一蹭就跳到"我的"；右下角"+"正在拇指位置，一碰就进新建页。同学想共用清单，做不到。

**第 1 个月末｜考试周、要不要买断**
任务堆到三十多条，搜索只搜名字，同名的搜出来还是一样。想买断，点进"完整版"看到「免费版同时追踪 1 个」——可我同时追踪了 3 个都成功了（"更改"按钮点不动，却提示"免费版同时追踪 1 个"）。到底几个？

### 4. 我最想要的 3 个功能

1. **应用锁 / 任务伪装**：家长翻手机时看不到内容，本地 PIN 就够。
2. **连击保护（每周一次补签）**：断一天不归零，或给一张"冻结卡"；断了要明确告诉我。
3. **昨天清单照抄到今天**：每天作业几乎一样，一条条建太慢。

### 5. 会不会说服家长给我买断

会去说，但说得费劲。好说的：一次性几块钱、不用联网、不用注册，家长最怕的"乱收费 / 要账号"都没有。难的是"我买到什么"：任务数量免费就无限，追踪我实测能开 3 个，剩下只有外观主题和"导出 JSON 备份"——而它只能导出、没有导入，卸载或换手机连备份文件一起没了。家长问"花钱能干什么"，我答不上来。如果"导出"能变成"能在新手机上恢复"，我当天就买。
