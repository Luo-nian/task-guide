# 使用测试 · 全职妈妈（32 岁 / 千元安卓 / 两个孩子 4 岁 + 8 岁）

> 我**没真机**（不能装不能点），故无"崩溃"条目，真机才能确认的标【推测】。路径简写：`手机/…` = `src/mobile/app/src/main/java/com/taskbar/app/`，`电脑/…` = `src/desktop/`。

---

### 1. 第一印象（≤3 句）

一眼干净、不像广告：米白纸底 + 赤陶色，字够大，"我的"页一张等级卡就把积分说清了。
但它是给"会设参数的人"做的：第一天我就被"每日/目标/限时/次数"拦住——我只想记"买菜"。
更糟的是它最该可靠的那件事——提醒，在我手上是坏的，还默不作声。

---

### 2. 一个月时间线

**第 1 天（趁娃睡午觉装的）** 20 分钟装完，首页只有右下角一个加号、没有引导。不知"买菜"选哪类，凭感觉选了"每日任务"，看到"每天 09:00"，以为时间设好了就保存。
→ 那个 09:00 只是显示，没保存。这条任务一辈子不会响。

**第 3 天（忘记设时间 / 设了没响）** 补上"睡前喂药"，认真点了 22:30 和响铃，当晚没响；又给"喝水 8 次"勾了振动，可这类任务连时间都没得填，界面照样显示设置成功。
→ 新建任务时它不去排闹钟，我得杀掉 App 重开才排得上。

**第 1 个周末（家庭采购清单）** 想把一周的菜、缴费、接送一次加进去。只能在"所有任务"页一条条新建，每条都重选类型、优先级、提醒。加到第 12 条娃醒了，剩下等我重来。
→ 没有批量加任务的路，只有给"步骤"粘 JSON 的路。

**第 2 周（被打断后状态不对）** 打印作业时在电脑上点了两条完成，回手机看还是待办。电脑首页更打自己脸：左边"今日待办 1 项未完成"，右边"今日进度 0/0、今日剩余 0 项"；手机同一件事写"1 个待完成"。
→ 两端同一屏三个数字，我不知道信哪个。

**第 3 周（孩子乱点 + 想起来才开 App）** 4 岁的娃乱点，长按进了多选，整屏变勾选框，没提示也不自动退出；我急着退，撤销条上"知道了"紧挨"撤销"，一点就把补救机会关掉。
→ 我"想起来才开 App"，而提醒只在我开过 App 那次才排得上。

**第 1 个月末（回看 + 要不要买断）** 40 多条任务、20 多条历史。主页没有搜索，历史页也没有搜索和筛选，找"上次交电费"只能翻日历。想备份：只有"导出 JSON 备份"、没有恢复入口，文件还在 Android/data 私有目录、没有分享键，我自己都取不出来。
→ 做完了调不出记录，备了份恢复不了。

### 4. 我最想要的 3 个功能

1. **"到点一定会响"**：能自检通知权限/精确闹钟/电池白名单，新建任务当场就排上（现在要杀掉 App 重开才算）。
2. **批量加任务**：像便签一样粘十行"买菜/交电费/接老大"，默认今天。
3. **能导入的备份 + 回收站**：JSON 一键恢复，单条误删给 6 秒撤销。

---

### 5. 会不会买断，为什么

会，但等它把提醒修好再买。¥5~12 就是一顿菜钱，为"同时追踪多个任务"我肯付；不注册、数据在自家手机、没广告，对带娃的人很值。
可这 App 唯一的硬承诺就是"到点提醒我"：新建任务不排、每日任务的 09:00 是假的、完成过的还会响、选了"仅电脑端"手机也响。提醒不可靠的任务清单，对我等于没有——我先当记事本用一个月，等提醒真响了再补买断。
