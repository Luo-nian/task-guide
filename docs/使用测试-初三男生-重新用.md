# 体验测试 · 初三男生（男·14·在读）· 重新用

> 情境：一个月前用过，**换机/卸载重装 → 数据全丢**，以老用户心态从零再来。

## 1 重装后的第一印象
打开是空白号：等级 Lv.1、徽章空、连续天数 0。设置页只有「导出」没有「导入」，旧的打卡记录一条都回不来。心里就一句：我白用了一个月。

## 2 时间线

- **换机当天**：装好第一件事点进设置找「恢复备份」→ 只有「导出 JSON 备份」，没有导入入口。旧手机导出的文件在 `Android/data/.../backups`，新手机文件管理器根本进不去。**一个月数据全丢，无法恢复。**
- **第 1 天**：重新建「数学作业/背单词/跑步打卡」三条每日任务。原那一个月的打卡、等级、徽章全不在，像新号。四条任务要一条条手敲。
- **第 3 天**：提醒偶尔不响（代码看 `rescheduleOne` 已接 TaskViewModel.kt:179/186，但需求写明「待真机验证」）。重建习惯很烦，漏设「每周一三五」一准又变天天提醒。
- **第 1 周末**：想连电脑同步 → PC 连不上，配对失效（手机重装 `auth_secret` 重生成 Auth.kt:51），得重新扫码配对。
- **第 2 周**：发现自己是老用户却零连续性——等级/徽章/连续天数归零，毫无「回来」的感觉，纯纯重练。
- **第 3 周**：买断授权码不在了（存 SharedPreferences License.kt:42，重装清空，备份也不含需求未修#2）。得翻爱发电邮件找码重新输入；码还在就不必重买，但 14 岁男生容易弄丢。
- **第 4 周**：结论——能忍，但**换机成本太高**。要是以后还换机，还得再来一遍。

## 5 我还会不会再用 / 会不会买断
**会再用**——提醒/打卡/升级这套对我（作业+背诵+跑步）有用，v5.23.0 以后提醒稳了、次数任务能累计、夜间看得清。
**但换机体验劝退**：数据全丢、无导入、配对重做、买断码要重找，等于每次换机重练一个月。**买断会买**（一次 ¥5~12，码还能重输），前提是先把码存好；若 App 能加「导入备份+配对迁移」，我愿意现在就买断当老用户福利。
