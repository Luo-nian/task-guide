# 使用测试 · 安保主管 · 第五轮 · 重启

## 1 我是谁 / 半年一句话
35岁，男，退伍军人，某园区安保主管，带12人三班倒。删后几天又装回 next任务，完全当新App从头用，后半段（约第3~6月）我只拿它当"个人销号台账"，关键事一律App+系统闹钟双保险，所以没再出事也没再删；最大遗憾仍是排班指派做不了。

## 2 时间线
### 重装第1周（6月初，删后几天）
还是想要清单销号那股劲，又装回来。从头建任务。首屏照样一堆游戏化元素，我直接关掉多余提醒强度只看"通知"。没记忆，所以又懵一遍，但轻车熟路些。这次手动把"锁屏隐藏任务名"关了才安心。

### 重装第1月（7月）
排班仍用 Excel（App指派不了人）。发现"手机左滑删/归档"和"电脑端右键菜单"挺好使，顺手清理很军事化。但电脑端提醒还是只在窗口弹，值班室电脑不开就白搭。

### 重装第3月（9月）
退役士兵补贴年审（一年一次）我设了提前3天提醒，这次响了，没丢钱，挺好。但消防巡检我不敢全信App，额外设了手机闹钟兜底。桌宠升级那些从没点开过。

### 第6月（9月底，半年末）
半年到。App没再删，但只当"个人台账+勾销"，关键事双保险。最大遗憾仍是排班指派做不了，12人班表还得另开 Excel。
