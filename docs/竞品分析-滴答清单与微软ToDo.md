# 竞品分析 · 滴答清单 vs 微软 To Do（补完篇）

## 一、滴答清单（TickTick）—— 订阅制的定价天花板

| 项 | 内容 |
| --- | --- |
| 定位 | 国内最主流的待办+日历+习惯+番茄全能工具（爱范儿评语） |
| 免费版 | ¥0：**9 个清单 × 每清单 99 条**、任务提醒**每次 2 条**、习惯 **5 个**、纪念日 5 个、附件 1 个/天、共享成员 2 人；日历/四象限/小组件只给"基础" |
| 高级会员 | **¥139/年**（TickTick 国际版 $35.99/年，挂牌价 $49.99；月付 $2.79~3.99） |
| 会员解锁 | 清单 299 个、每清单 999 条、提醒 5 条、日历视图无限制、时间线视图、微信提醒、全部外观主题、历史统计 |
| 评分 | App Store 4.9（美区 ~4.5 万评） |

### 对我们的启示（最值钱的三条）

1. **定价话术成立**：滴答一年 ¥139，我们 ¥12 **一次买断**——差 11.6 倍。体验测试里大学生原话「≤10 元当场买」，闪点用户的「不想被订阅绑架」群体，都是这条话术的靶子。**统一口径：「别人每年 139，我们一次 12，永久。」**
2. **免费限制"数量"是行业惯例**：滴答免费版卡 9 清单/99 任务/5 习惯/提醒 2 条——我们卡"同时追踪 1 个"**完全同构**，不显得抠。且滴答把"日历视图/小组件"也锁了（用户骂"免费月历变会员"正来自这类行为）；我们**同步、日历、提醒全部免费**，比滴答免费版慷慨——这是可宣传点：「免费版比滴答免费版能干」。
3. **它的会员大头是"容量+视图"**，不是核心体验 → 我们买断权益也该避开核心体验（提醒/同步），已经这么定了（协作/主题/上限），方向对。

## 二、微软 To Do —— 完全免费的大厂货

| 项 | 内容 |
| --- | --- |
| 定位 | 微软 365 生态的轻量个人清单；Outlook 标记邮件自动变任务 |
| 价格 | **完全免费，无任何付费档**（所有功能 0 元，靠 365 生态续命） |
| 强项 | My Day 每日规划、全平台、稳定同步、共享清单；App Store 4.72（26.4 万评） |
| 弱项 | **无习惯打卡、无番茄钟、无四象限、无游戏化**；列表结构最简陋（无分区/弱筛选）；数据存微软云；不碰微软生态价值骤减 |

### 对我们的启示

1. **"免费"不是死穴**：微软免费了 9 年也没杀死滴答——用户为"更全/更好用"付钱。我们打不过"免费"，但**微软恰好证明了我们两个卖点的稀缺性**：①它数据在微软云（我们局域网不出门）②它零游戏化零情绪反馈（我们桌宠+等级+连击）。
2. **别学它的"功能极简"**：它弱在"想记录什么都没地方放"。我们的步骤/次数/里程碑体系比它 rich，保持。
3. **My Day 值得抄**：每天清零的"今天要做"视图降低启动压力——我们主页"今日任务"已经同构，**不缺**。
