# 商业化执行手册（SOP）

> 目标：从**今天**到**收到第一笔钱**，每一步照着做。
> 适用主体：个人开发者（boss）。全部金额为 2026 年 9 月实际市价，已联网核实。
> 读法：先看 **§0 一页清单**，能立刻动手的就动手；需要决策的看 **§1**；细节按 S1→S18 顺序做。

## §0 一页清单（按顺序做，打勾用）


## §2 准备阶段

### S1 · 定死"三处一致"（最重要，改一次就重来）

- **软件全称**：`任务栏` 或 `任务栏 TaskBar`（软著证书上会印这个）
- **版本号**：`V1.0`（软著用大写 V；代码里 `versionName 1.0.0`）
- **包名**：`com.taskbar.app`（**注册后不能改**，Apple Bundle ID 同理）
- ⚠️ 小米开发者平台明确要求：**软著名称 = APP 备案名称 = 商店应用名称**，三者不一致会被驳回

### S2 · 个人资料备齐（一次性）

身份证正反面扫描/清晰照｜手持身份证照｜常用手机号｜常用邮箱（建议专用邮箱）｜应急联系电话

### S3 · 跨境收款（Apple/Google 打款用）

- 需要：**银行卡 SWIFT 代码**（8-11 位大写，打客服电话问）+ 卡号 + 账户名拼音
- Apple 后台路径：App Store Connect → 「业务 Business」→ 联系信息 / 银行业务 / 税务
- **W-8BEN 填法**：是不是美国居民 → 否；是否在美国从事商业活动 → 否；Individual；TIN 栏**填中国身份证号**；中美税收协定优惠 → 勾"是"；底部签拼音名
- ⚠️ **协议状态变成绿色 Active 之前，不要测内购代码**（会报 Empty Product / Payment Failed，很容易误以为代码写错）

## §3 资质阶段（国内上架的硬门槛）

### S4 · 软著登记（0 官费，60 天）

**入口**：中国版权保护中心 ccopyright.com.cn（全程线上，先实名认证）

**材料 1：源代码文档**
- 前 30 页 + 后 30 页（共 60 页），**每页 ≥50 行有效代码**
- 页眉正中：`任务栏 V1.0`；页码纯中文：`第 X 页`
- 不得大面积遮盖关键逻辑
- ✅ **我能代做**：写脚本从仓库抓代码 → 分页 → 加页眉页脚 → 导出 PDF

**材料 2：用户手册（15-30 页）**
- 结构：封面 → 目录 → 系统概述（软硬件环境、功能模块、技术架构）→ 安装与功能说明（图文）
- 页眉同样标 `任务栏 V1.0`
- ✅ **我能代做**：用现有文档 + 真机截图组装

**材料 3：申请表** 在线填（软件全称/简称/版本号/开发完成日期/首次发表日期/开发方式）→ 生成签章页 → 个人签字

**材料 4：身份证**正反面

**材料 5（2026 新增）**：**AI 合规及原创性声明** —— 本项目大量使用 AI 辅助编码，**必须提交**；用到的开源组件要在说明文件里写清来源与授权类型（Tauri=MIT/Apache-2.0、Compose=Apache-2.0、Room=Apache-2.0 等）

**周期与费用**：自助 **0 元 / 法定 60 自然日**｜代理 500-1500 元｜加急 1000-5000 元（20/10/5/3 工作日）

### S5 · 域名 + 国内云服务器

| 项 | 建议 | 价格 |
| --- | --- | --- |
| 域名 | `.com` 或 `.cn`，已实名认证，有效期内 | ¥60-80/年 |
| 云服务器 | 阿里云/腾讯云**轻量应用服务器**最低档，**包年包月 ≥3 个月**，备案期间剩余有效期 >1 个月 | ¥100-300/年（学生机更便宜） |

⚠️ 必须选**中国大陆地区**节点，否则办不了 ICP 备案。

### S6 · ICP 备案（在云厂商后台）

1. 云厂商备案系统 → 首次备案 → 填主体（个人：身份证/手机/邮箱/通信地址）
2. 填网站信息（域名、服务内容）
3. 上传身份证、手持照 → 云厂商初审（1-3 天）
4. **手机短信核验**（工信部发短信，24 小时内确认）
5. 省通信管理局审核 → 下号（共约 7-20 天）→ 在网站底部挂备案号

### S7 · APP 备案（工信部强制，2023-09 起）

- **入口**：云厂商备案系统的"APP 应用服务"（⚠️ **手机厂商应用商店不能代办备案**）
- **要填**：主体信息 + **APP 信息**（名称、**图标**、包名、**公钥 + MD5**、域名、服务类目、语种）
  - 安卓要 **APK 签名公钥 + MD5**（`keytool -list -v -keystore xxx.jks`）
  - 若以后发 iOS，需**单独走"新增备案"**填 Bundle ID
- **周期**：材料收到起 **20 天内**下号（材料有问题重新计算）
- **注意**：备案号不绑定渠道可复用；但同一 App 在各渠道**名称与功能必须一致**
- ✅ **我能代做**：从 keystore 提取公钥和 MD5、生成备案信息表

### S8 · 公安联网备案（双备案的第二道）

- 入口：beian.mps.gov.cn（公安部全国互联网安全管理服务平台）
- 材料：负责人证件、主办单位证件、域名证书、安全管理人/应急联系人证件
- 个人主体由**常住地址所属公安机关**网安部门审核
- 通过后把备案编号挂到网站底部

## §4 技术侧：会员系统怎么搭

### S9 · ⚠️ 一个必须先想明白的架构决策

**要做会员，就必须先有后端。** 因为权益（是否会员）不能只在客户端判断，否则一改本地数据库就破解了。
所以：**会员系统 + 跨端同步 = 同一个服务端**。这也顺带把"同步"这个主卖点做出来了。

### S10 · 数据库最小表结构

```
users        (id, email, created_at, platform_first_seen)
devices      (id, user_id, platform, device_name, last_seen_at)
orders       (id, user_id, platform, product_id, amount, currency,
              platform_txn_id, status, created_at, paid_at)
subscriptions(id, user_id, product_id, platform, started_at, expires_at,
              auto_renew, original_txn_id, status)
entitlements (user_id, feature_key, value, updated_at)   ← 权益的唯一出口
```

### S11 · 权益门禁点（对应你定的 4 条）

| feature_key | 非会员 | 会员 | 校验点 |
| --- | --- | --- | --- |
| `sync` | 关 | 开 | 同步接口的鉴权中间件 |
| `track_limit` | **1** | 不限 | **服务端也校验**（客户端提示 + 服务端拒绝第 2 个） |
| `export_json` | 关 | 开 | 导出接口 |
| `widget_theme` | 关 | 开 | 客户端拉 `entitlements` 后渲染 |

**必须做的 5 件事**：
1. **服务端校验**（客户端只是提示，不是防线）
2. **支付回调 → 写 orders → 写 subscriptions → 刷新 entitlements**（幂等，用 platform_txn_id 去重）
3. **离线宽限**：断网时保留权益 5-7 天（否则地铁里会员突然被降级，差评）
4. **恢复购买**（iOS 审核强制要求；Android 也要有）
5. **退款/退订回调**：订阅到期自动降级，不要永久给

### S12 · 定价落地

| 档位 | 国内 | 海外 | 说明 |
| --- | --- | --- | --- |
| 月 | ¥12 | $4.99 | |
| 季 | ¥28 | $11.99 | |
| 年 | ¥98 | $34.99 | **主推**，付费墙默认选中年付 |
| 终身 | ¥298 | $99.99 | 价格锚点，不是主推 |

- Apple：用 App Store Connect「订阅群组」建 4 个档（同群组内用户同时只能一种状态）
- **Product ID 命名带价格**：`pro_monthly_12` / `pro_yearly_98`（日后对账方便，定了基本改不了）
- 内购元数据**缺一项就卡 Missing Metadata**（最常漏的是 **Availability 销售范围**）
- 审核截图：640×920 ~ 3840×2160，**不能有 Alpha 通道**（导出成 JPEG）
- 沙盒测试员邮箱**必须是没注册过 Apple ID 的**（可用 `你的邮箱+test1@gmail.com`）

## §5 上架阶段

### S13 · Apple（App Store）

1. 注册账号 ¥688/年（用 Apple Developer App 在手机上注册，不要网页注册；中途别换设备/网络）
2. **立刻申请 Small Business Program**（25% → 12%，后台无直达入口，走官方申请页）
3. 填财务三关（§S3），等状态变 **Active**
4. 建 App ID（Bundle ID 选 **Explicit**，**不能改**）
5. 配置内购（§S12）
6. 真机 + 沙盒账号测内购（**模拟器测不了**）
7. 提交审核：隐私政策链接、截图、审核备注（写清订阅在哪、怎么测）、测试账号
8. 勾了欧盟销售范围就必须做 **DSA 商人申报**（填邮箱/手机/地址，**会公开**）

### S14 · Google Play

1. 注册 $25 一次性（需信用卡）
2. 上传 **AAB**（不是 APK），必须支持 **64 位**
3. 隐私政策链接、内容分级问卷、数据安全表单
4. ⚠️ **2026 年 Google Play 审核比 Apple 严得多，可能无预警封号且关联封杀**：正式包 / 测试包**物理隔离**，不要在同一个环境、同一个支付信息下操作多个开发者账号

### S15 · 国内五家渠道

| 渠道 | 账号费 | 认证周期 | 特别注意 |
| --- | --- | --- | --- |
| 华为应用市场 | 免费 | 1-3 天 | 简体中文名称必须与包内一致；**要求 APP 备案** |
| 小米应用商店 | 免费 | 1-3 天 | **软著 + APP 备案 都是必需**（官方 FAQ 明确） |
| OPPO 软件商店 | 免费 | 1-3 天 | 敏感权限要**逐条填使用场景 + 上传功能截图**，否则驳回 |
| vivo 应用商店 | 免费 | 1-2 天 | 流程最简 |
| 腾讯应用宝 | 免费 | 3-7 天 | 对启动速度、崩溃率有硬指标 |

**通用上架材料**：512×512 PNG 图标（须与包内一致）｜3-5 张 1080×1920 截图（真实、不重复、无其他品牌标识）｜隐私政策网址（线上可访问 + 与 App 内完全一致）｜用户协议网址｜**正式签名包**｜测试账号 + 操作步骤

**⚠️ 已知硬期限**：金标联盟（荣耀/OPPO/vivo/小米）要求 **2026-10-31 前**完成 Android 导航条 edge-to-edge 适配，逾期会在商店**打标提示风险**。

## §6 合规材料

### S16 · 隐私政策必须写到的 7 点

① 收集哪些数据（任务内容、账号邮箱、设备型号、崩溃日志）② 怎么用 ③ 是否共享给第三方（列出每个 SDK）④ 是否跨境传输（海外同步节点！）⑤ 用户如何导出/删除数据 ⑥ Cookie/本地存储说明 ⑦ 联系方式

**App 内必须**：首次打开弹窗展示 + 同意后才能用（不同意也要能用基础离线功能，否则违规）
**用户协议必须写**：订阅条款、自动续费与取消方式、退款政策、免责声明

### S17 · SDK 合规清单（每个都要记清单）

Tauri/WebView2 运行时、Room、WorkManager、Compose、若接支付：微信/支付宝/Google Play Billing/Apple StoreKit、若接统计：崩溃上报 SDK
→ 每个 SDK 在隐私政策里写明：名称、提供方、收集的信息、用途、隐私政策链接
