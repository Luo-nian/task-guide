# 使用测试 · 维修师傅 · 第五轮 · 卸载

### 1 我是谁 / 半年一句话
39 岁男，手机维修档口师傅，手上常压着七八台待修机、客户催取、配件到货周期飘、房租水电和孩子考试都挤在脑子里。这半年我先用 next任务 管客户取机、配件到货、房租水电、孩子考试和师傅进货日，用到第 3 个多月因为一条取机提醒没响、客户给了差评，当晚卸载；它本该是我档口最该靠得住的"记忆"。

### 2 时间线
**第1周（3月10日周一装上的头几天）**
在维修论坛看到推荐，装到我的工作安卓机上，顺手给店里 Windows 电脑也装了桌宠。打开有"四类任务"，但没人教我怎么分，我瞎建了一条"修 iPhone 12 换屏"。免费版只能同时盯 1 个任务，而我手上常压着七八台机器，第 3 天就点了买断（¥8）。桌宠能跟着手机同步，挺新鲜。

**第1月（4月上旬）**
每天把"老王取机 周五18:00""电池到货 周三"录进去。问题来了：我在电脑前焊板子时，提醒只在桌宠窗口里弹一下，修机器用的全屏软件一挡就看不见；手机那头我装机时顺手拒了通知权限（觉得任务软件要什么通知），后来顶上偶尔跳出一条红条说"通知未开启"，我忙着拆机没当回事也没点。等于自动提醒对我基本是聋的，全靠脑子记。

**第3月（6月上旬）**
靠"提前1天"提醒躲过一次电池晚到被客户催的尴尬，挺得意。但也开始烦：我设了"每天收工清工具"的习惯打卡，有个周日加班漏打，连续天数直接归零，没地方补，懒得再打。手机点完"取机"电脑要过一两分钟才动，能忍。

**删除（6月21日周六）**
傍晚老王按约 18:00 来取机，我正埋首修另一台，桌宠弹窗被维修系统盖住，手机又没响（权限早拒、红条早划掉），我根本不知道他到了。老王在门口干等 40 分钟，发火、退了检测费、还留了条差评。我回家越想越气，觉得这软件"关键时刻掉链子"，当晚卸载。之后取机承诺改回本子记 + 手机闹钟，反而没再出岔子。

**第6月**
（第4月初已卸载，余下时间没再用，见第4节。）

### 4 删除原因（卸载份专用）
直接原因：6月21日老王取机提醒未到达——电脑端只弹窗内提醒被维修软件遮挡，手机通知权限早拒且无有效补救，我误把主页红条当故障划掉。结果客户空等 40 分钟、退费 + 差评。当晚认定"它不靠谱"卸载，改用纸质台账 + 手机闹钟兜底。

### 5 结论
next任务在"记着帮我提醒"这件最要命的事上，对我这种常年泡在电脑前的维修工失灵了：电脑没有系统通知、手机权限一拒就哑、补救入口又太弱。它适合记不急的事，但客户取机这种要命的承诺，我不敢交给它。
