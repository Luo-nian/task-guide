# 使用测试 · 自由摄影师｜一个月（30 岁男 / 接单为主 / 同时跟 5~8 个客户项目）

### 1. 第一印象
审美真好，比滴答清单更像作品；可「一个客户一个容器、五步各带日期」做不了。

### 2. 一个月时间线
- 第 1 天：配对成，但手机必须停在「设置」页等电脑配对，一离开就超时。
- 第 3 天：5 个客户并行，只好把「客户+环节」写进任务名，用步骤装节点。
- 第 1 周末：步骤纯文本，没日期没提醒，交片日只能塞标题。
- 第 2 周：手机端追第 2 个客户被 toast 挡住（免费 1 个），我在电脑端改成 20 却没人拦。
- 第 3 周：外出断网，电脑端只有角落「未连接」；回工作室发现手机删的任务在电脑里还活着。
- 第 1 月末：历史页没搜索；导出的 JSON 猫在 Android/data 拿不出来。

### 4. 我最想要的 3 个功能
1. 客户/项目容器，节点各自带日期与提醒。
2. 按客户筛选 + 搜标题/备注/步骤，历史也要。
3. 能带走的备份：导出到自选目录 + 导入。

### 5. 会不会买断
会，但不是现在。¥5~12 买断不贵；可买断换来的只是"手机端多开几个追踪"，而电脑端本来就能白嫖 20 个（#4）。等「项目容器 + 能带走的备份」落地就买。
