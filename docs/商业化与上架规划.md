## 三、上架资质路线（boss 问的"怎么做"）

**国内上架硬门槛 = 软著 + APP 备案，两者缺一不可**（小米开发者平台明确：所有应用上架均需提供）。

### 3.1 软件著作权登记（✅ 我能代做大部分）

- 入口：**中国版权保护中心**（ccopyright.com.cn），**全程线上**
- 费用：**自助 0 官费**｜代理 500–1500 元｜加急 1000–5000 元（20/10/5/3 工作日）
- 法定周期：**受理起 60 自然日**
- 材料：
  1. **源代码文档**：前 30 页 + 后 30 页，**每页 ≥50 行**，页眉写「软件名称 + 版本号」，页脚/页码用纯中文「第 X 页」
  2. **用户手册 / 设计说明书**：建议 15–30 页，含封面 / 目录 / 系统概述 / 安装与功能说明，页眉同上
  3. **申请表**：在线填报后生成签章页，个人签字
  4. **身份证**正反面扫描件
- ⚠️ **2026 年收紧点**：① AI 辅助开发需提交「AI 合规及原创性声明」② 每页必须 ≥50 行**有效**代码、不得大面积遮盖关键逻辑 ③ 用了开源组件必须在说明里标注来源与授权类型

**我能直接做的**：
- ✅ 写脚本从仓库抓代码 → 自动分页（每页 50 行）→ 自动加页眉页脚 → 导出合规 PDF
- ✅ 生成用户手册（从现有文档 + 真机截图组装，含目录与功能说明）
- ✅ 给出申请表的建议值：软件全称 / 简称 / 版本号 / 开发完成日期 / 首次发表日期 / 开发方式
- ✅ 起草隐私政策 + 用户协议（文本 + 托管页面）
- ✅ **三处名称一致性核对**（软著名称 = APP 备案名称 = 商店应用名称，小米明确要求三者一致）

### 3.2 APP 备案（工信部，2023-09 起强制）

**前置条件（必须先有）**：
1. **域名**：在有效期内 + 已完成实名认证
2. **国内云服务器**：包年包月 **≥3 个月**，且备案期间剩余有效期 >1 个月（阿里云/腾讯云/华为云最便宜档即可，学生机更省）
3. 先完成 **ICP 备案**（有了域名 + 国内服务器才能做）

**流程**：主办者 → 通过**接入服务商**（云厂商）备案系统提交 → 材料核验 → 短信确认（beian.miit.gov.cn）→ 省级通信管理局审核 → **20 天内**下发备案号 → 工信部公示

**材料**：主体信息（个人：身份证 / 手机 / 邮箱 / 应急联系方式）+ ICP 负责人信息 + **APP 信息**（名称、**图标**、包名、**公钥 + MD5**、iOS Bundle ID、域名、服务类目、语种）

**坑（联网核实的官方答疑）**：
- ❌ **手机厂商应用商店不能代办备案**，必须走接入服务商（云厂商）
- ✅ 备案号**不绑定渠道**，可复用；但同一 App 在各渠道的**名称与功能必须一致**
- ⚠️ 已发布过安卓的，**新增 iOS 要单独走"新增备案"**
- ⚠️ 还有 **公安联网备案**（beian.mps.gov.cn）—— 国内是"双备案"

**成本**：域名 ~¥50/年 + 国内云服务器 ~¥60–100/月（学生机更低）+ **备案本身免费**

### 3.3 各商店上架材料（通用）

应用图标 **512×512 PNG**｜截图 **3–5 张 1080×1920**｜**隐私政策网址**（必须线上可访问，且与 App 内完全一致）｜用户协议网址｜**正式签名包**（不能 debug 签名）｜测试账号（需登录的话必须给）｜支持 64 位

## 四、风险提示

- **Google Play 审核比 Apple 严得多**：2026 年 Google Play 应用总量缩减 47%，新包稍有不慎可能**直接封号**且无预警，还会**关联封杀**（同一环境/支付信息下的其他账号）。→ 正式包与实验包必须物理隔离。
- **美国市场 iOS 内购同比增速仅 3%**（历史最低），欧洲 +22% 才是增长点 → 出海投放重心建议放西欧。
- 国内安卓渠道抽成 **50%**，比 Apple 中国区（25%/12%）高一倍 → 国内优先引导官网/微信支付直充。
