> 配套：`需求文档-任务指南.md`（v1.2 定稿）、`db/schema.sql`、`docs/同步协议.md`

## 1. 总体架构

```
┌─────────────────────────────┐         局域网(热点/WiFi)         ┌─────────────────────────────┐
│  手机端 (vivo / Android)     │  ◄──── HTTP + WebSocket ──────►  │  电脑端 (Win11 / Tauri)     │
│  Kotlin 原生 App（服务器）     │                                 │  桌面悬浮挂件（客户端）        │
│                             │                                 │                             │
│  ├─ UI        Jetpack      │   mDNS 发现 / 手动输入 IP        │  ├─ UI        HTML/CSS/JS   │
│  │            Compose       │                                 │  │            (毛玻璃+淡金)  │
│  ├─ 数据库    Room/SQLite   │                                 │  ├─ 数据库    SQLite         │
│  ├─ 小部件    AppWidget     │                                 │  ├─ 托盘      系统托盘        │
│  ├─ 提醒      WorkManager   │                                 │  ├─ 窗口      置顶/透明/拖动  │
│  │            + 系统通知     │                                 │  └─ 同步      增量+WebSocket  │
│  └─ 服务器    Ktor          │                                 │                             │
│               HTTP+WS       │                                 │                             │
└─────────────────────────────┘                                 └─────────────────────────────┘
         ▲ 数据源（权威副本）                                              │ 客户端（本地缓存）
```

**核心设计原则**：
1. **手机是权威数据源**（服务器），电脑是客户端（缓存）
2. 双端都写本地 SQLite → 通过增量同步 + 时间戳冲突解决保持一致
3. 断连时双端各自独立可用，重连后自动合并

## 2. 关键决策

| 决策 | 选择 | 原因 |
|---|---|---|
| 跨端 ID | **UUID（非自增）** | 双端都可能插入新数据，自增 ID 必冲突 |
| 删除方式 | **软删除（deleted 标记）** | 保证同步可传播删除操作 |
| 冲突解决 | **updated_at 时间戳，后写覆盖** | 单人使用，简单可靠 |
| 同步方式 | 首次全量 + 日常增量 + WebSocket 实时推送 | 兼顾首次连接和日常低流量 |
| 局域网发现 | mDNS + 手动 IP 双通道 | mDNS 自动，失败时手动兜底 |
| 通知 | 系统通知（Channel + 锁屏显示） | 无需任何第三方推送服务 |
| 提醒调度 | WorkManager（手机）+ 电脑端本地定时器 | 手机离线也能准时提醒 |

**提醒调度逻辑（WorkManager）**：
- 每个带 `due_at` 的任务 → 注册一次性 WorkRequest
- 到点触发：按 `reminder_strength` 设置发通知
  - standard：一条通知
  - repeat：未确认则 5 分钟后再发（最多 3 次）
  - alarm：循环响铃，必须手动确认（确认后发广播关闭）
- 重复任务：完成后自动计算下一次 `due_at` 并重新注册
- 未完成警告：`due_at` 过期 1 小时后未完成 → 升级一级提醒强度

**小部件刷新**：追踪任务状态变更时，通过 `AppWidgetManager.updateAppWidget` 推送新数据；小部件点击事件 → PendingIntent 打开对应界面。

## 4. 电脑端模块划分（Tauri 2）

```
desktop/
├── src/                     # Rust 后端
│   ├── main.rs              # 入口
│   ├── db.rs                # SQLite（rusqlite，复用 db/schema.sql）
│   ├── sync.rs              # 同步客户端（HTTP + WebSocket）
│   ├── tray.rs              # 系统托盘（最小化到托盘）
│   ├── window.rs            # 窗口管理（置顶/透明/无边框/拖动/贴边）
│   └── reminder.rs          # 本地提醒定时器 + 系统通知
├── ui/                      # 前端（原生 HTML/CSS/JS，不引框架保轻量）
│   ├── index.html           # 挂件主界面
│   ├── style.css            # 毛玻璃 + 淡金主题
│   ├── app.js               # 界面逻辑 + Tauri invoke 桥接
│   └── components/
│       ├── track-card.js    # 追踪任务卡片（原神图二样式）
│       ├── task-list.js     # 今日任务列表
│       ├── progress-bar.js  # 完成进度条
│       ├── countdown.js     # 倒计时
│       └── habits.js        # 习惯状态
├── tauri.conf.json          # 窗口配置（透明/置顶）
└── Cargo.toml
```

**窗口形态实现**：
- 竖条贴边：窄窗口（如 260×600）+ 贴边吸附（距屏幕边缘 <40px 时吸附）
- 悬浮卡片：默认尺寸（如 340×480）+ 自由拖动
- 置顶：`window.set_always_on_top(true)`
- 透明毛玻璃：`window.set_transparent(true)` + CSS `backdrop-filter: blur()`
- 托盘：`tray-icon` 插件，点击托盘图标切换显示/隐藏

**开机自启**：Tauri 的 `autostart` 插件（写入注册表 Run 项），设置里可开关。

**离线处理**：WebSocket 断开 → 显示"已离线"横幅 + 继续用本地缓存；重连成功 → 拉取增量并合并。

## 5. 同步设计要点

- **增量游标**：每个变更记录 `updated_at`（毫秒），增量查询 `WHERE updated_at > last_sync`
- **变更传播**：本地任何写操作 → 立即通过 WebSocket 推送 `{op, entity, uuid, data}`
- **冲突**：收到远端变更时比较 `updated_at`，本地更旧则覆盖，本地更新则忽略（单人使用够用）
- **全量同步**：首次连接 `GET /api/sync/full`，包含 tasks + steps + habit_logs
- **自动备份**：电脑端每次同步成功后，将手机返回的数据导出 `taskguide-backup-YYYYMMDD.json` 存到 `桌面/TaskGuide备份/`

详见 `docs/同步协议.md`。

## 6. 开发顺序（建议）

| 阶段 | 内容 | 依赖 |
|---|---|---|
| P0 骨架 | 目录结构 + schema.sql + 协议文档（已完成） | — |
| P1 手机核心 | Room 数据层 + 任务 CRUD + 步骤 + 追踪状态机 | Android Studio |
| P2 手机提醒 | WorkManager + 通知 3 档 + 未完成警告 | P1 |
| P3 手机小部件 | AppWidget 追踪卡片 + 直输 | P1 |
| P4 手机服务器 | Ktor HTTP API + WebSocket 推送 | P1 |
| P5 电脑端 | Tauri 窗口 + 本地库 + UI（追踪卡片/列表/进度） | — |
| P6 电脑同步 | 同步客户端 + 离线缓存 + 自动备份 | P4+P5 |
| P7 联调 | 双端实测（热点环境） + 错误报告 | P1-P6 |

**开发环境要求**：
- 手机端：Android Studio（最新稳定版）+ JDK 17 + Android SDK 34
- 电脑端：Rust 工具链（rustup）+ Node.js（Tauri CLI 用）
- 双端构建产物均为本地安装，无需上架应用商店
