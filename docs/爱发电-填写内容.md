# ⭐ 怎么拿到收款链接（你最关心的）

爱发电有**两种链接**，你需要的是**第二种**：

### ① 主页链接（人人可赞助任意金额）
- 位置：后台「**我的**」→「**个人主页**」→ 复制链接
- 形如：`https://afdian.com/a/nexttask`
- 这个链接**先发我也行**，我可以先放进 App 的「关于」页

### ② ⭐ 商品/付费内容链接（固定价 ¥12，别人点开就能买）
这是真正要用的：
1. 后台左侧找「**内容管理**」或「**我的商品**」→ **新建**
2. 类型选：**付费内容**（或「商品」，哪个有就选哪个）
3. **标题**：`next任务 · 买断授权`
4. **价格**：`12`
5. **正文**：把上面「创作介绍」那段贴上（或者精简成两行说明）
6. **发布** → 进这个内容的详情页 → 右上角「**分享**」→ **复制链接**
7. 形如 `https://afdian.com/item/xxxxxxxx` ← **把这个发我**

### ③ 提现
后台「**收益管理**」→ 提现到**支付宝**（所以支付宝必须先实名）。
爱发电抽 **6%**，到账很快。
