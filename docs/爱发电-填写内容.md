# ⭐ 怎么拿到收款链接（你最关心的）

爱发电有**两种链接**，你需要的是**第二种**：

### ① 主页链接（人人可赞助任意金额）
- 位置：后台「**我的**」→「**个人主页**」→ 复制链接
- 形如：`https://afdian.com/a/nexttask`
- 这个链接**先发我也行**，我可以先放进 App 的「关于」页

### ② ⭐ 商品/付费内容链接（固定价 ¥12，别人点开就能买）
这是真正要用的：
1. 后台左侧找「**内容管理**」或「**我的商品**」→ **新建**
2. 类型选：**付费内容**（或「商品」，哪个有就选哪个）
3. **标题**：`next任务 · 买断授权`
4. **价格**：`12`
5. **正文**：把上面「创作介绍」那段贴上（或者精简成两行说明）
6. **发布** → 进这个内容的详情页 → 右上角「**分享**」→ **复制链接**
7. 形如 `https://afdian.com/item/xxxxxxxx` ← **把这个发我**

### ③ 提现
后台「**收益管理**」→ 提现到**支付宝**（所以支付宝必须先实名）。
爱发电抽 **6%**，到账很快。

## 7 · ⚠️ 「赞助方案 / 订阅方案」这一页怎么填（按月订阅页）

**先分清两个东西，别混：**

| 入口 | 是什么 | 我们要不要 |
| --- | --- | --- |
| **赞助方案 / 订阅方案**（= 你现在这页） | **按月**订阅，粉丝每月付一次 | ❌ 不是我们要卖的东西 |
| **商品 / 付费内容**（如果后台有这个入口） | **一次性**购买 | ✅ **买断放这里最干净** |

**两种情况：**
- 后台**有**「商品 / 付费内容」→ 把买断放那儿（¥12 一次性），这页只当"打赏"随便填
- 后台**只有**这页（注册时强制至少一个方案）→ 按下面填，但**奖励详情务必写明"一次即可、不必续订"**，
  否则买家会以为要每个月都付

### 这页的填法

| 字段 | 填什么 |
| --- | --- |
| 赞助昵称（方案名） | `支持我` |
| 金额 / 月 | `5` ← 平台最低就是 ¥5 |
| 奖励详情 | `凭订单号发邮件索取 App 授权码，解锁：同时追踪多个任务、导出备份、外观主题。赞助一次即可，不需要每个月都赞助，授权码永久有效。` |
| 添加方案图片 | 用 `src/docs/assets/爱发电方案图-800x800.png`（已出好，正方形） |
| 高级选项 → 赞助折扣 | **关闭折扣**（我们不做长期订阅，开了像在催续费） |

### ⭐ 关于「4.9」这个数

看到爱发电**最低 ¥5.00**，你写的「超过 4.9 元」应该就是这个意思（≥5）。
于是现在有两个价：

- 平台底线：**¥5**（满 5 就能索取授权码）
- 你最早定的买断价：**¥12**

**建议写法**：金额填 `5`（过平台门槛），奖励详情里补一句
「**建议 12 元；满 5 元即可索取授权码**」—— 门槛过得去，也把人往 12 引。

## 8 · 「高级选项」里每个勾怎么选

| 选项 | 选不选 | 说明 |
| --- | --- | --- |
| 添加自动回复 | ✅ **认证后用** | 固定文案自动回复（例："已收到，我尽快把授权码发你"）。需认证创作者 |
| ⭐ **添加自动随机回复** | ✅✅ **首选** | 官方说明就写着「**适用于激活码、礼品码场景**」—— 付款后**自动从码池随机发一个码**给买家。**全自动，不需要任何服务器**。需认证创作者 |
| 补货API | ❌ 不用 | 让码池自动补货要接 API → 需要服务器 → 破坏零成本路线。**我们自己手工补池**（一条命令出一批） |
| 自定义信息收集 → 需求邮寄地址 | ❌ 不要 | 授权码走线上，不需要地址 |
| 独立方案 | 只有一个方案时无所谓 | ⚠️ **保存后不可更改** —— 想清楚再点保存 |
| 季费 / 年费 | ❌ 不用 | 保持**按月支付**（我们不做订阅，按月只是为了过平台门槛） |

### ⚠️ 一个风险先说清楚

「自动随机回复」是**随机挑一行**发出去 —— 理论上**同一个码可能发给两个买家**。
我们的码是**买断制、不绑账号**，所以最坏情况也就是两个人各解锁一台机器，损失可控。

补救办法：
1. 池子放大（比如一次放 50 个），降低碰撞概率
2. 定期整批换新（旧的在台账里划掉）
3. 买家把码反馈回来时，我能从码里的订单号（`B1-01` 这种）认出它是池里第几个

### 现在需要你做的一件事：**申请「认证创作者」**

「自动回复」「自动随机回复」「补货API」三个**都要求认证**。认证要实名资料，**只能你本人办**。

**没认证之前也能开卖** —— 走手工发码，我这边 30 秒一单，不影响收款。
