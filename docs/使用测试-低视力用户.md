# 使用测试 · 低视力用户（一个月）

> 30 岁男，电话客服居家，矫正视力 0.1（法定视力障碍）。手机开 **TalkBack + 系统字体最大 + 高对比**，靠"听 + 放大"操作。仅看代码与截图，未装机；行号以源码为准。

## 1 第一印象
装完能进、能建任务，图标按钮大多带了 `contentDescription`，这点比想象中好。但**所有反馈都靠"看"**：完成提示、入库提示、错误全是自绘 Toast，读屏不读；批量操作只能靠手势进。对"靠听完成全部操作"的我，等于半残。

## 2 一个月时间线
- **D1（装 + 建第一条）**：读屏念出"添加、追踪、完成"，建任务顺畅。但保存后没有任何"已建好"的播报，靠听没法确认，只能摸着看。
- **D3（改时间）**：详情页"每天 HH:MM"药丸点三下才中（太小），且改完无语音确认。
- **D1 周末（批量建）**：想用"所有任务"页批量选 → 长按进多选摸不准、滑动连选读屏做不了，最后一个个点开建，放弃批量。
- **D2 周（读状态/提醒）**：TalkBack 能念"追踪中·停止""当前追踪中"，文字状态还行；但顶栏那个**同步小圆点**和**追踪数字角标**完全听不到，不知手机和电脑连没连。
- **D3 周（误触挽回）**：详情页删除已加二次确认（好）。但完成一条后画面只是"任务没了"，没有"已完成 +N 积分"的播报，常被我当成没点上、又点一遍。
- **D1 月末（续用/买断）**：功能全、不上云正合我意，但"听不到反馈"天天消耗我，仍在犹豫。

## 4 「无障碍缺口」清单（逐条）
1. **`Screens.kt:2123-2128` 同步圆点**：仅颜色，无文字/`contentDescription` → 听不到"手机↔电脑 已连/未连"。补文字状态。
2. **`Screens.kt:2251-2260` 追踪数角标**：独立 Box，未并入"追踪"按钮语义 → 听不到数量。并入按钮 label。
3. **`UiFoundation.kt:39-68` + `:698-913` Toast/庆祝**：非 `LiveRegion` → 全部操作反馈对读屏不可见。统一播报通道。
4. **`Screens.kt:1565-1582` 多选入口**：仅长按+拖拽 → 读屏用户进不去批量模式。加显式"批量"按钮。
5. **`Screens.kt:1501-1512` 搜索框**：无 label → 报"编辑框，无标签"。补语义标签。
6. **小目标点击区**：`TaskDetailScreen.kt:1075/1354`、`UiFoundation.kt:450`、`SettingsScreen.kt:283/998` 等多处 Box.clickable 无 48dp 最小区 → 低视力难点中。加 `minimumInteractiveComponentSize()`。
7. **`Screens.kt:2183` 等级**：图形徽章无文字 → 听不到等级。补"Lv.N"。
8. **`TaskDetailScreen.kt:717-738` 提醒通道行**：内联 chip 在最大字号下拥挤/换行 → 读屏顺序乱、易点错。改纵向或允许滚动。

## 5 会不会继续用 / 买断
**想买，但先修 #1–#4 才肯付。** 不注册、不上云、手机当服务器，刚好护住我"数据隐私 + 居家低调"的顾虑；图标基本都带描述、状态大多有文字，比很多 App 强。可卡我的是**"靠听完成全部操作"**：完成没播报、同步状态听不到、批量进不去——这三条不修，每天用都在赌。补 LiveRegion 播报 + 显式批量按钮 + 同步文字状态，成本很低，改完第二天就买 ¥5~12 那档。
