## 三、⭐ 它的差评 = 我们的机会（这部分最值钱）

来自应用宝、西西软件园、什么值得买等平台的**真实用户抱怨**：

| # | 用户原话（摘要） | 对我们的启示 |
| --- | --- | --- |
| 1 | 「一个待办清单**要通讯录和定位权限**干嘛？我记买菜的还得报坐标吗…**怕它后台偷偷传数据**」（西西软件园） | ⭐⭐ **隐私是它的软肋**。我们**零账号、零云端、数据只在局域网** —— 这是能直接打出去的差异点 |
| 2 | 「一年前**免费的月历视图，开始要充会员**了，有点不讲武德」（夜雨聆风） | ⭐ 用户最恨"免费功能变付费"。我们承诺：**核心清单永久免费**，只对"重度功能"收费 |
| 3 | 「**完成任务的可点区域有点小**，加个**滑动完成任务**就好多了」（什么值得买） | ⭐ **滑动完成 = 高频刚需**，成本极低，必须补 |
| 4 | 「对于任务的**设置有点繁琐**」（同上） | 我们要坚持"少填字段"，新建任务默认值要聪明 |
| 5 | 「界面可以再正式点」/「担心没有付费功能活不下去」 | 说明用户**愿意为好东西付钱**（支持收费的评论不少）—— 我们的 ¥12 买断有市场 |

## 四、结论：我们该学什么、不该学什么

### ✅ 值得抄（按性价比排序）

| 优先 | 功能 | 为什么 | 成本 |
| --- | --- | --- | --- |
| 1 | **滑动完成任务** | 用户亲口说"用了就离不开" | 低（列表项加手势） |
| 2 | **手机桌面小部件（列表 / 日历）** | 留存利器；我们已有 widget 基础 | 中 |
| 3 | **番茄钟 / 专注模式** | 与我们的"追踪"天然咬合，还能当**买断权益** | 中 |
| 4 | **多提醒（提前 N 天 + 提前 N 小时）** | 提醒系统刚大修完，扩展顺手 | 中低 |
| 5 | **四象限看板** | 优先级字段已有，只是加个视图 | 低 |
| 6 | **悬浮速记（点桌宠记一笔）** | 桌面端已有桌宠，天然入口 | 中 |
| 7 | 倒数日 / 时间轴视图 | 锦上添花 | 低–中 |

### ❌ 明确不抄（会毁掉我们的定位）

| 不做 | 原因 |
| --- | --- |
| **云同步 / 账号体系** | 那就要服务器 → 零成本路线崩掉，还要备案；而且**"不上传"正是我们最强的卖点** |
| **任务共享/协作** | 同样要服务端。真要做也只能走**局域网内共享** |
| 订阅第三方日历 / 墨水屏客户端 | 投入产出比太低，不是学生个人项目该碰的 |

### ⭐ 我们的定位（一句话）
> **闪点清单是"更全的工具"，我们做"更想打开的清单"**：
> **零账号零云端（数据不出门）** + **桌宠游戏化（打卡有情绪反馈）** + **一次性买断（不搞订阅）**。

功能数量上我们永远追不上一个有公司团队的 6 年老产品 —— **别在功能广度上跟它拼，在"隐私 + 情绪价值 + 不割韭菜"上赢**。

## 五、给 boss 的两个提醒

1. **它的"免费"是公司烧钱换口碑**（6 年、有备案、有团队）。我们是一个人、零预算，所以**不能承诺"永久全免费"** —— 我们承诺的是"**核心永久免费 + 一次买断解锁重度功能**"，这个说法要统一。
2. 想体验它的话**不用你去应用商店下载**了 —— 上面的信息足够。真要装，**注意它索要通讯录/定位权限**（这也正好印证第 1 条差评）。
