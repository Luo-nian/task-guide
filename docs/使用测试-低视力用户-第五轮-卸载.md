# 使用测试 · 低视力用户 · 第五轮（卸载）

### 1 我是谁 / 半年一句话
30 岁男，低视力（矫正 0.1，法定视力障碍），在家做电话客服，手机开 TalkBack + 系统字体最大 + 高对比模式，靠读屏播报和手势操作。半年里我先用了约三个月 next任务 记用药、会议、生活琐事；因一次关键提醒失灵、加上批量操作读屏完全做不了，当场卸载。余下时间没再装回（改用系统提醒 + 墙上便利贴）。

### 2 时间线
**第1周**：搜"任务清单"装了 next任务，图它不注册、数据不过云（客服怕通话内容上云）。¥5 买断。记滴眼药水和每天两三个客服会。读屏能读大部分文字，完成弹层那句"+5 积分"也能播报（liveRegion 已修，我实实在在听到了）。
**第1月**：习惯"连续天数"很激励，滴眼药连到 21 天。但列表里任务旁的"提前提醒"小钟不读（Screens.kt:828），我分不清哪个设了提前提醒；任务行要左滑才出"编辑/归档/删除"（Screens.kt:290），TalkBack 下我根本不知道有这手势，找不到删除入口，急了只能去电脑端删。
**第3月（删除）**：一次重要客服会前 15 分钟该响的提前提醒没响——前一天我误触关了提醒（开关点击区小易误碰），又因读屏听不到"提前提醒"标识没察觉，会上被主管点名。当晚想批量清过期任务，批量依赖滑动/长按（Screens.kt:1683），读屏下划不出来，越弄越烦，觉得"关键时刻靠不住"，当场卸载。
**第6月**：已卸载，改用手机系统提醒 + 墙上便利贴。便利贴越贴越乱，但再没动过本 App。

### 4 ⭐「无障碍缺口」清单

| 位置 | 缺什么 | 影响 |
|---|---|---|
| 任务列表行 | 可见的编辑/归档/删除入口（仅左滑手势） | 读屏用户无法删除/归档任务 |
| 任务列表行尾部 | 提前提醒状态的可朗读标识（ic_clock null） | 不知提醒是否设置，易误关漏事 |
| 任务详情页 | 添加步骤/推进步骤/提醒图标的 contentDescription | 关键操作读屏无语义 |
| 多选/批量 | 读屏可达的多选控件（依赖长按+滑动） | 无法批量管理 |
| 全局 | 随系统放大的动态字号 | 低视力下文字过小 |
| 多处图标按钮 | contentDescription（见问题清单 4/5/6/9/10） | TalkBack 仅报"按钮" |

### 5 删除原因
因重要会议提前提醒被误关、读屏无法感知提醒状态，加上批量清理在读屏下完全操作不了，认定其不可靠而卸载；之后用手机系统提醒 + 墙上便利贴替代，便利贴越贴越乱。

### 6 结论
功能合我心意（隐私不上云、桌宠连续打卡真能激励我滴眼药），但低视力下"自己删自己、自己批量"几乎不可能，提醒状态又对读屏隐形。一次真实误事后我失去信任卸载了。它救过我的用药习惯，却在最该可靠的提醒上掉了链子。
