# 使用测试 · 低视力用户 · 第五轮（重启）

### 1 我是谁 / 半年一句话
30 岁男，低视力（矫正 0.1），在家做电话客服，手机开 TalkBack + 最大字体 + 高对比。上半年里我先装了 next任务 用了约三个月后卸载；重装一次后（完全不记得之前怎么用）从零用到半年末，记用药、会议、琐事，靠电脑端桌宠兜底。

### 2 时间线
**第1周（重装后）**：便利贴贴满显示器边框，有次记错会议时间，又想起这 App 的桌宠和连续打卡确实让我坚持了滴眼药，于是重新装。完全像第一次用，重新摸索。立刻又撞上：列表"提前提醒"小钟不读（Screens.kt:828）、任务行左滑手势找不到删除（Screens.kt:290）。
**第1月（重装后）**：重新建用药 + 会议清单。习惯连续天数从 0 重来（之前 21 天记录随上次卸载没了——那次没导出备份）。详情页加号/推进箭头不读（TaskDetailScreen.kt:228、:792）再次让我卡住。
**第3月（重装后）**：已摸索出用电脑端（桌面挂件/桌宠）删任务更稳，手机端只记和听提醒。批量清过期任务仍靠电脑端。这期间发现"导出/导入备份"功能（之前根本不知道），开始定期导出到本地。
**第6月（重装后）**：重装后约满三个月，用满半年。整体能用，但无障碍缺口仍在：图标按钮缺 contentDescription、左滑手势对读屏不可用、字号写死。我已学会 workaround（靠电脑端 + 读屏朗读任务名），没再卸载。

### 4 ⭐「无障碍缺口」清单

| 位置 | 缺什么 | 影响 |
|---|---|---|
| 任务列表行 | 可见的编辑/归档/删除入口（仅左滑手势） | 读屏用户无法删除/归档任务 |
| 任务列表行尾部 | 提前提醒状态的可朗读标识（ic_clock null） | 不知提醒是否设置，易误关漏事 |
| 任务详情页 | 添加步骤/推进步骤/提醒图标的 contentDescription | 关键操作读屏无语义 |
| 多选/批量 | 读屏可达的多选控件（依赖长按+滑动） | 无法批量管理 |
| 全局 | 随系统放大的动态字号 | 低视力下文字过小 |
| 卸载流程 | 备份提醒（导出/导入隐蔽） | 重装即丢全部记录 |

（本份为重装后记录，无删除事件。上次删除原因见「卸载」份：重要会议提前提醒被误关、读屏无法感知提醒状态，加批量清理读屏下做不了，认定不可靠而卸载。）

### 6 结论
重装后我靠电脑端桌宠兜底，手机端只记和听，反而稳了。功能与隐私设计都合我意，连续打卡真救了我的用药。但左滑手势、缺 contentDescription 的图标、写死字号这三道坎对低视力始终没变——它能陪我用到半年末，是因为我学会了绕开，不是因为它对我无障碍。
