# 文案 · 文字提示排查 v1

> 起因：boss 「把所有文字提示都排查一遍 两个要求 第一 要官方但不要AI味 第二 是否有必要
> 之前已经有很多文字提示让我觉得没必要了 现在说不定还有 你自己排查！」
> 排查范围：**两端所有面向用户的文字**（标签 / hint / 副标题 / 说明 / 按钮 / toast / 弹窗 / 空状态）。
> 排查日期：2026-09-21 ｜ 手机端 v5.21.x ｜ 电脑端 v5.21.x
> 不包含：`LicenseCeremony.kt`（本轮禁区）、安卓 `res/` 字符串资源（本轮禁区）、
> 等级名/座右铭（数据源 `LEVELS`）、`widget.html`（本轮不在可改清单内）。

## 0 · 判定尺子（本轮统一口径）

**必要性**
1. 不看这句，用户会不会做错？会 → 留。
2. 标签已经自解释（"通知栏""振动""次数"）？→ 没必要，删。
3. 别处已经说过一遍？→ 删后说的那句。
4. 这句话是不是用来填版面的空白？→ 删。

**文风**
- 不要：句式对称排比 / 总分总 / 情感标签堆砌 / 形容词通胀（非常·极其·完美）/ 永远正确的废话。
- 不要：居高临下（暗踩同行、道德宣言、自夸式谦虚）。
- 要：官方——措辞准确、有边界感、不承诺做不到的事；中文简洁说人话；不堆感叹号；不用 emoji 装饰。
- 自检问法：**这句话如果是朋友当面对我说的，会不会觉得他在装？会，就删。**

优先级：**能删就删 > 短句 > 长句**。
