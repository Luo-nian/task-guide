## 一、这是什么项目

「手机+电脑」双端任务清单 App，个人开发者作品（boss 一人产品，AI 实现代码）。

- **手机端**：Kotlin + Jetpack Compose（`src/mobile/`），Android
- **电脑端**：Tauri2（Rust `src/desktop/src/` + 原生前端 `src/desktop/ui/`），Windows 任务栏桌宠
- **同步**：无账号无云 —— 手机当服务器，电脑经 WS/HTTP 同 WiFi 连接；LWW（最后写入胜）冲突策略
- **商业化**：免费版 + ¥12 买断授权码（爱发电收款、手工发码，`node src/tools/license/gen-license.mjs issue`）；签发靠 ECDSA 私钥（只在 secrets/，仓库只编公钥 → 仓库可公开）
- 免费版限制：同时追踪 1 个任务（`License.FREE_TRACK_LIMIT`）

## 五、验证方法论（血泪换来的，别再踩）

1. **⭐⭐ adb 广播验证法在本机作废**：`am broadcast -n` 返回 completed 但 receiver 收不到（vivo 拦截）。9-22 的"广播验证 5/5"是假阳性。
   **正确姿势**：改库 due_at（now+N 秒）→ force-stop → 推回 db（本地 sqlite3 checkpoint 后，push 到 /data/local/tmp + chmod 644 + `run-as cp`，删手机端 -wal/-shm）→ 冷启动重排 → 等真实触发 → 验 shared_prefs 旗标/通知/UI。
2. **adb install** 的 `Performing Streamed Install` 不是成功 —— 必须 `tail -2` 看 Success + 核对 `lastUpdateTime`。
3. **装机用 ASCII 路径**（release 里中文名 apk 只作存档，装 build/mobile/.../app-debug.apk）。
4. **adb 验证脚本 ≤10 分钟**（长了会话失效）；重连和操作写同一条命令。
5. **改前先 diff 源与副本**（`diff -rq`）；Windows python 读不了 `/c/...` 路径。
6. **真机数据**：`run-as com.taskbar.app` 读 `databases/taskguide.db`（WAL 模式，-wal 文件要一起拉）；prefs 在 `shared_prefs/taskguide_prefs.xml`；崩溃日志 `files/crash.log`（当前 0 行）。

## 六、编译（全离线）

- **手机端**：`build/mobile/` 副本编译。流程：改 `src/mobile/...` → 同步改动文件到 `build/mobile/app/src/main/...` → `build/mobile` 下 `gradle assembleDebug --offline`（JAVA_HOME 指 `toolchain/jdk17/...`）。产物 → 复制到 `release/next任务-vX.X.X-调试版.apk`。
- **电脑端**：`build/desktop-src/` 编译（**不是 build/desktop**）。同步 `src/desktop/` 改动 → cargo build --release --offline（环境变量见 README）→ `build/desktop-target/release/taskbar-desktop.exe` → 复制到 `release/`。**换 exe 前先确认 boss 没开着客户端**（占用会 Device or resource busy）。
- Room 迁移：当前 version=5（MIGRATION_4_5 加 remind_ahead_min）。**加字段必须写迁移并注册**，boss 手机上有真实数据（任务「健身」+习惯）。
