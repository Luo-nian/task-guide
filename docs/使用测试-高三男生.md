# 使用测试 · 高三住校男生｜一个月（17 岁 / 高三 / 住校 / 晚 11 点断网）

### 1. 第一印象
不注册、不联网、数据只在自己手机里，对手机被父母管控的我是刚需；可"倒计时"只有高考在我心里，App 里没有。

### 2. 一个月时间线
- 第 1 天：没有科目维度；建的「背单词 6:30」当晚没响，要冷启动才排上。
- 第 3 天：没做完的不变色、不写"逾期"，欠几张卷自己记。
- 第 1 周末：想按科目批量建，只能一条条手打，"新建分类"点不出来。
- 第 2 周：历史页没搜索框；"所有任务"只搜任务名，搜备注没反应。
- 第 3 周：限时只能填"几点截止"，没法说"这卷 90 分钟"；"延迟1天"只延 1 毫秒。
- 第 1 月末：断一天连续天数归零；导出备份里带着配对密钥。
