# 体验 · 独居老人的女儿（38 岁 / 外地工作 / 首次安装 / 无使用记忆）

> 设定：父亲 68 岁独居、高血压+糖尿病。我在自己手机首次安装。

## 1 第一印象

暖色字大，适合老人。但**这是单人清单，没有家人看护/远程查看，我在外地接不进父亲手机**。

## 2 我的 5 个使用场景

**① 远程替他建药任务**：让他点「+」→ 拧时间。主页干净但一天两次要建两条，且无代建入口。卡：**我无法在他手机上操作**。

**② 偷看"今天吃药了吗"**：打开自己手机一片空白。卡：**数据只存本地，异地无法同步**【已核实】`SyncService.kt:149-161`、`SettingsScreen.kt:880`。

**③ 他说"今天没响"，我判断真假**：无提醒/打卡日志。卡：**责任归属糊涂**；`ApiRoutes.kt` 无日志接口。

**④ 把我的设备与父亲配对**：他进设置→配对。卡：**必须同 WiFi + 父亲手动点允许**【已核实】`SettingsScreen.kt:552-555`、`Auth.kt:188-194`、`SettingsScreen.kt:669-699`，外地无法完成。

**⑤ 帮他换机/重装恢复**：导出 JSON 落 `Android/data/...` 私有路径【已核实】`SettingsScreen.kt:970-973`，进不去；无导入入口，授权码不随备份【已核实】`License.kt:41-43,102-104`。

## 4 ⭐ 颠覆性建议

**颠覆1｜远程照护当一等公民。** 首启问"是否由家人代管"，给子女只读入口。

**颠覆2｜照护者日报。** 短信/微信推送"吃药/未吃/离线"，不破坏不上云卖点。

**颠覆3｜重做配对。** 从"同 WiFi 双向确认"改为"邀请链接+老人一次确认"。

**颠覆4｜责任面板。** 女儿可见"已提醒/已打卡/未处理/在线"，把"吃了吗"变确定。
